# Same-assay availability audit — 2026-10-16

[availability.json](availability.json) records source-verified availability and deterministic query/control selection, **without chemical scores or activity-discrimination estimates**. This follow-up was motivated by the earlier assay-heterogeneity audit; it is not a preregistered analysis of the original controls or a replacement for the frozen generation benchmark.

The 15,533 retained ChEMBL measurements produced 5,890 assay-context/family records. All 1,586 encountered contexts have counts in this record. Under the fixed minimum of five active and five inactive reference families, with different query family/scaffold, all six targets have at least two eligible contexts. Seed-42 hash selection with two contexts per target, one query per context and at most ten controls per label produced 12 queries and 197 pairs.

The record contains source URLs/SHA-256 values, curation and selection policies, per-context availability, exclusion counts, selected query IDs and artifact hashes. Full observation/pair files are generated by the [reproduction protocol](../../../docs/ASSAY_MATCHED_CONTROLS.md); the [bundled ChEMBL snapshot](../research-validation-20261016/chembl-source-snapshot.zip) provides the raw inputs. Panel hashes include local paths and can change after relocation; scoped record identities, selected pairs and counts are the chemical reproducibility targets.

ChEMBL-derived data are attributed to [EMBL-EBI ChEMBL](https://www.ebi.ac.uk/chembl/) under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). This audit filters and groups those observations, preserving assay-local disagreements and unresolved metadata. The data license does not alter the code license. Same assay ID, structured human metadata and null variant annotations do not establish identical conditions or experimentally verified wild-type constructs.
