# Synthesis workflow integration validation

Recorded on 2026-10-11. This is one preselected, retrospective integration case,
not a held-out accuracy benchmark or an experimental synthesis-success study.
The design comes from the authors' published SynLlama example outputs; the
oxazole reference is a hypothetical O/S scaffold variant.

| Check | Result |
| --- | --- |
| SynLlama | Actual local 1B-2M-91rxns model, NVIDIA L40, four seeded samples |
| Catalog | 238,542 unique registered structures; one uninstantiated dummy-atom record excluded |
| Rules | 91 registered reaction SMARTS |
| Live scaffold hopping | 5 unique accepted products from 4 model proposals |
| Hit expansion | 4 products after excluding the unchanged design; reuses the actual live proposals |
| Route replay | Every selected route regenerates the exported product from catalog entries |
| 3D evidence | Exported candidate and reference poses reproduce pharmacophore scores within 0.0001 |
| Identity | Isotope and stereochemical identity retained in exported SDFs |
| Same candidate conformation | Pairwise distances agree between hit- and design-aligned poses within 0.001 Å |
| Python 3.10 / RDKit 2025.9.6 | 133 tests passed, including the optional model runtime and legacy compatibility |
| Python 3.10 / RDKit 2026.9.1 | 130 passed; optional model-runtime module and ODDT check skipped |
| Python 3.11 and 3.12 | 130 passed on each; the same optional modules skipped |
| Minimum base dependencies | 110 passed; optional modern 3D/model/ODDT modules skipped |
| Transformers runtime contract | 4.51.3 and 5.0.0 pass local safetensors/PyTorch-bin tests |

`validation.json` records exact asset hashes, source revisions, model settings,
search limits, seeds, ensemble settings, elapsed times, all outcome counts and
artifact hashes. `verified_routes` counts route instances, including repeated
proposals and expansion paths; it is not a count of distinct experimental routes.
Results are deduplicated by canonical isomeric product identity. Deuterated and
unlabelled products are distinct identities; isotope-specific quantum/kinetic
effects are not modelled in the heavy-atom shape/pharmacophore score.

The selected result tables, score records and both candidate/reference SDFs are
included here. Full raw proposals, route evidence and manifests are generated by
the workflow and retained locally under `benchmark-results/synthesis-live-hop-final`
and `benchmark-results/synthesis-live-expansion-final`. Their hashes are recorded
in `validation.json`. Model weights and the vendor-derived catalog are external
assets, not redistributed in this repository. Structure-hash IDs in this snapshot
are not supplier SKUs, and snapshot membership does not establish current stock.

To reproduce after preparing the assets described in
[the synthesis guide](../../../docs/SYNTHESIS.md):

```bash
chembounce-synthesis \
  --hit 'Cc1coc(NC(=O)c2cccnc2N2CCOCC2)n1' \
  --design 'Cc1csc(NC(=O)c2cccnc2N2CCOCC2)n1' \
  --config benchmarks/synthesis_smoke_config.json \
  --output benchmark-results/synthesis-live-hop-final
```

Use a fresh output directory. To reproduce expansion without resampling the model:

```python
from pathlib import Path
from chembounce_synthesis.workflow import load_config, run

config = load_config("benchmarks/synthesis_smoke_config.json")
config["mode"] = "expand"
config["provider"] = {
    "kind": "saved",
    "path": str(Path("benchmark-results/synthesis-live-hop-final/proposals.json").resolve()),
}
design = "Cc1csc(NC(=O)c2cccnc2N2CCOCC2)n1"
run(design, [design], config, "benchmark-results/synthesis-live-expansion-final")
```

The limits in the checked-in smoke configuration are intentionally small and
fully recorded. These candidate counts are case-specific, not expected yields
for arbitrary targets. No synthesis yield, biological activity, selectivity,
protection strategy or condition feasibility has been experimentally established.
