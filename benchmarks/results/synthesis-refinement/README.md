# Multi-seed refinement and accumulated candidate validation

This is one integration case using **saved actual SynLlama outputs**, a historical
catalog snapshot and independent registered-rule replay. It is not a held-out
success-rate benchmark or experimental synthesis evidence. The pretrained
chemical inventory is unknown; model generalization cannot be inferred here.
The pinned upstream prompt contains no molecule-specific examples, so no prompt
overlap is claimed.

The case and withheld-precursor setup are the same as the earlier
[expansion comparison](../synthesis-expansion/README.md). The exact target precursor
and its deuterated counterpart are unavailable in the test catalog. The required
core is `c1cccnc1N1CCOCC1`; all accepted products must retain it and the design's
Murcko scaffold. These are analogues of that design, not distinct new scaffold families.

## Protocol and observations

Both stages use projection k=3, beam=6, max combinations=256, max expansion routes=128,
max screened product/design pairs=64, and no similarity cutoffs. Screening uses
12 conformers at seed 42. Each stage refines its top 10 products with 24 conformers
at seeds 42, 43 and 44. These bounded integration search settings differ from the
larger projection budgets in the distributed model configuration.

| Stage | Alternative blocks / rounds | Screened pool | Refined results |
| --- | --- | --- | --- |
| First stage, including the earlier small-search pool | 16 / 1 | 14 | 10 |
| Continue from the first stage | 16 / 2 | 36 | 10 |

- All 4 earlier returned products survived the first-stage carryover.
- All 14 first-stage screened products survived continuation; lost products: 0.
- The old best candidate, omitted by an independent wider search, is recovered through its saved route.
- The earlier run's files were unchanged. Both stages use the saved provider;
  continuation performs no model inference.
- All selected routes were independently replayed using a subset of catalog rows
  looked up by ID in the original snapshot. Required cores and both Tanimotos were rechecked.
- All 20 selected result entries were checked against exported candidate/reference SDF coordinates.
  Maximum pharmacophore discrepancy was 1.4645446e-05 (tolerance 1e-4).

The first-stage top candidate is `O=C(Nc1nc(Br)cs1)c1cccnc1N1CCOCC1`. Its three-seed score range is
0.991460–0.991560, with median 0.991460.
Its hit/design Tanimotos are 0.576271 / 0.773585.
These heuristic similarities are not activity or synthesis-success probabilities.
See the seed tables for sampling sensitivity of all shortlisted products.

Pool sizes count successful initial 3D scores, while `eligible_products` in the
audit also includes molecules that subsequently fail 3D scoring. Refinement only
covers the shortlisted products, so it does not establish an optimum over the
full pool. Timing in the audit is descriptive: other local checks ran concurrently,
and continuation can reuse in-process conformer caches.

## Reproduction and files

After recreating the licensed external assets and masked catalog using the earlier
comparison instructions, run:

```bash
python benchmarks/validate_synthesis_refinement.py \
  --config benchmark-results/expansion-input/config.json \
  --hit 'Cc1coc(NC(=O)c2cccnc2N2CCOCC2)n1' \
  --design 'Cc1csc(NC(=O)c2cccnc2N2CCOCC2)n1' \
  --include-run benchmark-results/expansion-comparison-reproduced/small \
  --output benchmark-results/refinement-validation
```

The config and earlier small-run directory above are created by the reproduction
steps in the linked expansion comparison. Ensure the saved-provider config uses
the stated projection budgets, masked catalog, registered rules, `core_smiles`,
and `preserve_design_scaffold: true`. An equivalent local config is also accepted.
The script sets the expansion, conformer, refinement and output budgets described above.
It requires fresh output directories and asserts pool retention, original-file
immutability, route replay, core retention, Tanimoto and SDF consistency.

Runtime package source hashes in `audit.json` match implementation commit
`933fdde860c7162b3ba5de2d65b2a315e3955fd9`. The continuation manifest may name the later
test-only commit; runtime module hashes are identical. RDKit 2025.9.6, NumPy 1.26.4
and SciPy 1.13.1 were used.

Tracked files contain the compact audit, both screening/final tables, every seed's
scores, the top-ranked molecule's four SDFs for each stage, and test transcripts.
Complete proposals, routes, refinement diagnostics and all poses remain under
`benchmark-results/refinement-validation/` locally and are regenerated by the
script. Catalog/model assets are external and are not redistributed here.

Final local checks: 159 tests passed in the primary environment; minimum dependencies
passed 127 tests with four optional-module skips. The implementation also passed
[the six-job CI matrix](https://github.com/jyryu3161/chembounce/actions/runs/38137618594).
