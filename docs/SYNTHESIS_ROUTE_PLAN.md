# 합성 경로 우선 개발 계획 (2026-10-24)

**상태: P1 미완료. 실제 비교 v2에서 전체 경로가 지지된 입력은 4/12개로 기준선 5/12개를 넘지 못했다. 최종 qualified 후보 3개는 한 입력에서 나온 별도 성과다.** 첫 실제 비교의 0/12개에서 회복했지만 고정된 채택 기준에는 미달하므로 P1 성공으로 채택하거나 `develop`에 병합하지 않는다. 현재 `--recommend`/`recommend()`의 기본값은 `qualified-selective-engineering-v7`이며, v7은 v5의 경로·근거 할당(`inherit-v1`)을 계승한다. v6의 변경된 할당은 명시적으로 선택하는 과거 프로필일 뿐 기본값이 아니다. 현재의 구조, 입체화학, 원래 입력에 대한 유사도, 전체 경로 재생, 계산 근거, 3D 및 최종 qualification 관문은 그대로 유지한다.

**최신 진전:** 대칭 고리의 공동 입체 패턴을 구분한 결과 두 입력의 최종 구조6개·2개에는 고리 패턴이 남아 있었지만 필요한 pyrazole 연결 문맥이 없었다. 이어 이미 선택된 고리 형성 규칙의 원시 역반응12건을 조사해, 끊어진 고리의 방향족 표시가 전구체에 남아 검색 힌트 정리가 실패하는 문제를 찾았다. 원자 출처와 양쪽 반응 템플릿으로 확인되는 **복사된 힌트의 방향족 표시만 정리하는 일반 수정**을 구현했고 집중 테스트77개와 독립 코드 검토를 통과했다. 다음은 같은12입력·자산·상한에서 사전 공급을 재검증하는 것이다. 아직 새로운 전체 경로 지지 결과는 없으며 실제 성적4/12개와 P1 미완료 상태는 유지한다.

## 현재 우선순위와 다음 산출물

목표는 **원 입력과 필요한 구조·입체 특징을 공유하면서 scaffold가 달라지고, 구체 원료부터 정확한 최종 생성물까지 이어지는 검증 가능한 합성 경로를 가진 후보**를 제안하는 것이다. 합성 용이성 점수나 반응 이름만으로 이 목표를 충족했다고 판단하지 않는다. 카탈로그·규칙 재생, 단계별 전방 예측, 문헌·실험 근거는 서로 다른 수준의 근거로 표시한다.

**개발 순서:** ① 현재 1–2단계 경로의 정확성과 전방 지지 → ② 단계별 반응 조건·선택성·원료 출처 → ③ 같은 생성물의 대체 경로와 비용 배분 → ④ 독립 입력에서 일반화 검증이다. 더 깊은 경로 탐색이나 후보 수 확대보다, 제안한 경로를 사람이 검토할 수 있고 근거가 부족한 단계를 식별할 수 있게 만드는 일을 먼저 한다. 아래 실행 계획이 우선이며, 뒤의 버전별 기록은 당시 판단을 보존한 이력이다.

| 현재 구분 | 확인한 상태 | 남은 문제 |
|---|---|---|
| 경로 생성·재생 | 실제 카탈로그 원료와 규칙을 사용하는 최대 2단계 생성, 정확한 중간체·생성물 재생, 원자·입체 감사가 구현돼 있다. | 규칙 재생 성공만으로 실제 반응 조건·선택성이 입증되지는 않는다. |
| 전체 경로 계산 지지 | 실제 비교 v2: 4/12입력, 고유 입력/생성물 8쌍, 지지 경로 9개. | 기준선 5/12입력을 넘지 못했다. 단계 하나의 불일치도 전체 경로 성공으로 세지 않는다. |
| 입력과의 유사도·scaffold 변경 | 원 입력 기준 지문·입체 anchor·극성·3D 관문을 사용한다. 최종 qualified 3개는 한 입력에서 나왔다. | 주변 고리 교체 성과를 중심 scaffold 교체로 표현하지 않는다. 독립 입력에서의 성능은 미확인이다. |

### 다음 구현의 실행 단위

다음 반응 역할을 고려한 원료 선택은 경로 공급을 늘렸지만 새 입력을 확보하지 못했다. 이어 완료한 공동 고리 진단은 일부 실패 구조에 고리 입체 패턴이 남아 있음을 확인했다. 단순히 원료 순위를 더 바꾸기 전에, 이미 선택된 고리 형성 규칙의 힌트 처리 오류를 수정했다. 다음 실행은 **이 일반 수정 하나의 공급 효과를 고정12입력에서 검증**하는 대조다. 공동 고리 관측 자체를 새 최종 관문이나 후보 승인 근거로 사용하지 않는다.

**전체 anchor 진단(v1)의 예외와 검증:** `CHEMBL4869-query-1`에서는 한 anchor가 원료1개와 최종 생성물1개에서 보존됐으므로 모든 구조가 전부 없었다고 표현하지 않는다. 같은 입력의 다른1경로에서는 원료의 전체 query 문맥이 최종 생성물에서 더 이상 관측되지 않았다. 이 경로는 기존 off arm에도 있어 새 원료 선호 정책의 회귀가 아니며, 원자 계보를 검사하지 않았으므로 입체중심의 실제 소실·반전으로 단정하지 않는다. 나머지 필수 anchor까지 모두 보존한 최종 생성물은 없었다.

v1 진단은 RDKit 버전과 소스·자료 해시를 고정했으며 작은 대조9개, 최종218건의 원래 판정과 통과 여부 일치, 전후 해시, 독립 검토를 통과했다. 입력/SMILES 기준 구조 검사338건·별도 계량한 부분구조 요청1,084회·원래 anchor 검사218회를 기록했다. 원래 검사와 query 컴파일의 내부 매칭은1,084회에 포함되지 않으며 별도 상한을 명시했다. 새 경로 생성·전방 모델·3D 호출은0회다. 이 v1 진단 자체는 production 개선이나 새 전체 저장소 테스트 결과가 아니다.

**공동 고리 진단 완료:** 지정 입체중심 전체와 직접 이웃을 남긴 query를 만들고, 양끝의 대칭 교환을 순서 없는 공동 위치 집합으로 비교했다. 진짜 chiral 매칭은 유지하며 여러 위치 집합·매칭 상한·입체 손실은 미확인으로 남겼다. 같은338구조·218경로 상태에서 매칭361회로 두 입력의 최종 구조6개·2개에 공동 고리 패턴을 확인했다. 기존 전체 anchor 문맥 소실 사례에서도 공동 고리 패턴은 남아 있었다. 원료 TSV 재조회·반응 생성·모델·3D 호출은 없었으며, 이 보조 관측으로 최종 통과 후보가 늘어난 것은 아니다.

**역반응 힌트 정리 오류 수정:** [원인·수정 검증 기록](../benchmarks/results/synthesis-route-development-20261023/reverse-hint-aromatic-query-repair-v1.json)은 원시 역반응12건의 원자 분할 통과와 전구체24개의 `SANITIZE_KEKULIZE` 오류를 확인했다. 비고리 원자에 남은 방향족 표시를 제한적으로 정리한 뒤, 보존한 원시 분자에 실제 `normalize_reverse_hint`를 적용해24개 모두 정리되고12개 approximate 쌍이 복구됨을 확인했다. 실제 typed 검사는 첫 역할6/12개·둘째 역할0/12개 통과로 완성된 typed 쌍0개였다. 잘못된 역할을 통과시키거나 전하·입체를 바꾼 결과가 아니다. 원료 카탈로그에서 실제 반응 가능한 조합을 얻는지와 모든 단계의 전방 지지는 다음 고정 대조에서 검증한다.

이 작업과 병행할 보고 개선은 **단계별 근거 누락을 바로 찾을 수 있는 경로 상세 표시**다. 반응 조건·당량·보호기·경쟁 부위·원료 출처를 각 단계에 연결하고, 문헌의 유사 반응과 정확한 반응 관찰을 구분한다. 데이터 확보와 검증은 별도 작업으로 남기며, 빈 필드를 채운 것만으로 합성 가능성 근거가 개선됐다고 세지 않는다. P1 통과 이후에도 독립 입력 평가와 조건·선택성 근거 확보가 남으므로 P1 완료를 논문 수준 검증 완료로 표현하지 않는다.

### 경로 결과에 반드시 보여줄 내용

후보마다 **입력 구조 → 최종 구조 → 원료 → 중간체 → 단계별 생성물**을 추적하고, 기존 저장 결과 검토 화면에 다음 항목을 연결한다. 새 점수 하나로 모두 합산하기보다 어떤 단계가 확인됐는지 보여주는 것을 우선한다.

- 원 입력 기준 2D 유사도, 3D 형태·약리 특징·입체 보존, 변경된 scaffold와 주변/중심 골격 변경 구분.
- 경로 ID와 정확한 단계 의존 관계, 원료 구조·카탈로그 ID·출처, 정확한 중간체와 최종 생성물.
- 단계별 규칙 재생·원자/입체 감사, 전방 예측의 일치/불일치/미평가/실행 오류와 근거 파일.
- 시약·조건·선택성·보호기·관찰 기록의 출처와 검토 상태. 알려지지 않은 항목은 그대로 표시.
- 대체 경로, 총 단계 수, 예측 호출·검색 비용, 예산으로 평가하지 못한 항목. 검증된 견적이 없으면 합성 비용·수율·성공 확률은 제시하지 않음.

계산 경로의 **규칙 검증**, **모든 단계 전방 지지**, **출처를 확인한 문헌/관찰 근거**, **실제 합성 확인**은 별도 상태다. 최종 `qualified` 역시 현재 설정의 계산 관문 통과를 뜻하며 이 상태들을 대체하지 않는다.

### 다음 실험의 범위와 중단 기준

v14의 저장 결과 분석을 완료했다. 새 경로 4개는 모두 `CHEMBL3334418-query-1`의 1단계 경로이며, 아래 후속 고정 대조에서 전방 예측과 모두 불일치했다. `CHEMBL4247-query-2`의 경로 집합은 그대로다. 따라서 사전 통과 입력이 6개라는 이유만으로 전체 모델 비교를 반복하지 않는다. 평가된 불일치와 기존 미평가 경로를 구분해 다음 개선안을 설계한다. 같은 정확 경로라도 이전에 미평가된 경로는 실패로 간주하지 않는다.

`CHEMBL4247-query-2`의 typed 역반응 질의에서 두 번째 ordinary 원료를 원 입력 지문으로 선택하는 [고정 대조](../benchmarks/results/synthesis-route-development-20261023/typed-guide-second-control-v1.json)를 완료했다. 검색 문맥 3개의 기존 첫 원료·역할·입체 조건을 유지했고, 후보를 고정한 뒤 실제 두 내부 workitem과 외부 반응을 연결했다. 기존 대조의 감사 통과 경로 2개를 재현했으며, 새 선택은 다른 2단계 경로 1개를 만들었다(원 입력 bit Tanimoto 0.368932). 그러나 기존 두 생성물은 소실됐고, 한 내부 workitem에서는 다음 반응 부위를 가진 중간체가 0개였다. 순위 계산 24,573회와 입체 검사 3회, 연결 대조의 생성 호출 32회·감사 3회를 기록했다. 요약 문맥의 원료가 실제 call19와 다른 문제는 실행 전에 수정하고 원래 호출의 ID·순서를 고정했다. 이 결과만으로 typed 정책을 production에 확대하지 않는다.

**고정 7단계 전방 모델 대조 완료 — typed 확대 미채택:** [실행 기록](../benchmarks/results/synthesis-route-development-20261023/typed-guide-forward-control-v2.json)에서 양성 대조와 기존 평가 경로의 상태·예측 원문을 재현했다. 새 경로의 외부 단계는 rank1 일치했지만 내부 단계에는 정확한 일치가 없고 유효하지 않은 예측 하나가 있어 `partially_evaluated`였다. 전체 경로 지지는 확인되지 않았으며, 완전한 불일치나 실험 합성 실패로 해석하지 않는다. 원래 미평가였던 기존 경로는 이번 별도 진단에서 내부 불일치·외부 일치였고, 과거 기록이나 주 지표 4/12개는 변경하지 않았다. 이 고정 후보를 재시도하거나 다음 순위 후보로 바꾸지 않고 typed 확대는 미채택으로 남긴다.

첫 대조는 생성/사전 감사 상한16과 실제 전방 근거 감사 상한64를 혼동한 검증 코드 때문에 양성 대조 1회 호출 후 중단됐다. 당시 예측 원문은 보존되지 않았으며 이 한계를 명시했다. 수정 실행에서는 모델 로드 전에 원본 한도별 바인딩과 실제 한도64의 감사를 모두 확인하고, 평가 원문을 assertion 전에 저장했다. 수정 실행은 7회·입력339·출력973토큰, 중단 실행까지 합치면 8회·입력400·출력1,150토큰이다. 모델·원료·규칙·관문·후보는 바꾸지 않았으며, 중단 실행을 화학적 실패나 새 후보 평가로 세지 않는다.

**대체 마지막 규칙 대조 완료 — P1 개선안으로 미채택:** [고정 대조 기록](../benchmarks/results/synthesis-route-development-20261023/competing-final-rule-control-v2.json)에서 기존 실제 비교의 전체 선택 경로 16개와 마지막 반응물 순서가 같은 14개 그룹을 사용했다. 각 입력의 기존 `outer_rules_selected` 순서, 입력별 규칙 검사 최대128회·그룹별 호환 대체 규칙 최대2개를 유지했다. 기존 16개 경로가 모두 같은 관문과 전체 감사를 통과했고, 규칙 검사218회·생성 호출8회로 생성물 인스턴스8개·경로9개를 만들었다. 통과 경로7개는 모두 원래 선택된 생성물과 같았다. `CHEMBL4247-query-2`의 다른 생성물2개는 원 입력 극성 특징 보존 기준에서 탈락했다. **새 통과 생성물과 새로 확보한 입력은 모두0개**이므로 이 가설은 현재 P1 개선안으로 채택하지 않는다.

후보 집합을 고정한 뒤 저장된 요청24개의 예측 원문을 검증했다. 대체 규칙 경로5개가 모든 단계의 저장 예측과 일치했지만 기존 생성물에 대한 별도 경로이며, 탈락한 두 생성물에는 모델 지지를 주장하지 않는다. 새 모델·3D 호출은0회이고 실제 주 지표4/12개는 유지한다. 전체 감사23회는 기존 대조16회와 신규7회를 합한 진단 비용이다. 같은 예산의 production 결과가 아니며, 향후 구현 시 규칙 검사·감사 비용은 기존 한도 안에서 공유해야 한다.

첫 실행은 설정 투영에서 qualified 모드·refinement를 누락해 첫 입력 후보 생성 전에 중단됐다. 수정본은 저장된 전체 유효 설정을 고정하고 12입력 모두를 카탈로그 로드 전에 검증했다. 실패한 원본·로그를 보존했고, 이 오류를 화학적 실패로 세지 않았다. 수정 실행은 12입력 모두 정상 종료했으며 소스·카탈로그·규칙 해시가 전후 일치했다.

**신규 v14 경로 전방 대조 완료 — 신규 지지0/4개:** [고정 실행 기록](../benchmarks/results/synthesis-route-development-20261023/v14-new-routes-forward-control-v1.json)은 v13 대비 새 경로4개 전부를 저장 순서대로 평가했고, 기존 1단계 양성 대조의 상태와 예측 원문을 재현했다. 5개 모두 원 입력 사전 관문을 통과하고 원본 한도16/64와 실제 근거 한도64의 전체 감사를 통과했다. 신규4개는 모두 유효하고 완료된 top3 예측에 정확한 생성물이 없어 `mismatched`였다. 공통 원료 요청은 캐시로 공유해 실제 모델 호출3회·입력175·출력555토큰·캐시 적중2회를 사용했다. 감사14회·검증5회·규칙 호출19회를 별도 계량했고, 소스/자산/계획 해시는 실행 전후 일치했다. 이 결과는 새 실제 전체 패널 비교가 아니며 주 지표4/12개를 바꾸지 않는다.

브로마이드 원료 쌍의 예측은 여러 부위 치환 또는 황 연결 변화, 알코올 원료 쌍의 예측은 여러 부위 치환과 일부 beam의 추가 `Na+`를 포함했다. 이는 저장 예측에서 관찰한 차이이며 실제 반응의 생성물·선택성으로 확정하지 않는다. 원래 생성물과 다른 치환 수, 입체 표기, 이온을 제거해 일치를 만들지 않는다. 명시적 fallback 변경은 사전 경로 공급만 늘린 실험 구현으로 유지하며 합성 경로 지지 개선으로 채택하지 않는다.

**반응 부위 진단 완료 — 일괄 제외하지 않음:** [59경로·94단계의 구조 진단](../benchmarks/results/synthesis-route-development-20261023/reactive-site-diagnostic-v2.json)을 정확한 입력/그래프/단계/생성물로 저장 근거와 연결했다. 단계별 상태는 일치20·불일치10·부분 평가1·미평가63건이며 새 모델 호출은 없다. 여러 원료 역할 매칭은 일치20건 중1건, 불일치10건 중7건에 나타났지만, 반복 요청·위치 이성질체·개발 선택이 포함된 기술 통계다. 일치 단계12건에도 다른 호환 규칙이 존재하므로 다중 매칭이나 경쟁 규칙을 일괄 제외하는 정책은 도입하지 않는다. `uniquify=True`의 원자 집합 기준 개수와 모든 대칭 매핑의 완전성을 구분한다. 첫 분석은 후보 없는6입력의 초기화되지 않은 manifest 형식을 처리하지 못했으며, 구조 계산을 보존한 뒤 JSON 연결 부분만 수정했다. 없는 맥락 개수는0이 아니라 미확인으로 남겼다.

**내부 규칙 준비 예산 진단:** 현재 실행은 outer plan을 순환하지만 내부 규칙의 준비는 plan/slot 순서다. 12입력 모두 static/outer 비용을 포함한512회 상한을 소진했고 일부 고유 target은 검사를 받지 못했다. [규칙 한 개씩 순환하는 대조](../benchmarks/results/synthesis-route-development-20261023/inner-rule-preparation-control-v1.json)는 기존12입력의 선택·검사 비용을 재현했으나, 변경 쪽10입력에서 유효 내부 규칙 선택이0개가 돼 기각했다. 주어진 우선순위에서 너무 얕게 분산한 결과이며 모든 배분 방식의 실패로 일반화하지 않는다. 동일 product-template의 boolean 결과 캐시는 CPU 호출을 일부 줄일 수 있지만 규칙 entry마다 검사 비용을 계속 청구해야 하므로512회 안에서 탐색 범위를 늘리는 해결책으로 채택하지 않는다.

**큰 중간체 질의 우선 정책 — v15 기각·기존 코드 복원:** [계획 전용 대조](../benchmarks/results/synthesis-route-development-20261023/inner-rule-preparation-control-v2.json)는 고유 target/rule 쌍을 늘렸지만, [전체12입력 v15](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v15.json)에서 사전 통과 입력은6→6개, 생성물56→33개, 경로59→33개로 줄었다. 새 생성물5개와 소실28개를 모두 기록했고, 2단계 경로는35→9개, 1단계 경로24개는 유지됐다. 기존 qualified 생성물3개도 이번 집합에서 모두 사라졌다. 평가한 구현은 `8bb5104`에 보존했으며 [집중 테스트68개·독립 코드 검토](../benchmarks/results/synthesis-route-development-20261023/large-target-preparation-review-v1.json)를 통과했지만 경로 공급 개선으로 이어지지 않았으므로, runtime/test를 `ba639c8`의 내용과 바이트 단위로 같게 복원했다. 이68개 검증은 기각한 구현의 기록이며 현재 복원 소스의 새 전체 테스트 결과가 아니다.

복원 후 `tests/synthesis/test_route_first.py`와 `tests/test_phase_telemetry.py`의 집중 회귀 테스트64개, Ruff 검사·포맷 검사를 통과했다. runtime/test의 기존 버전과 바이트 일치, 근거 파일 해시9개, 12입력 요약 합계와 문서 링크도 확인했다. 이는 복원 검증이며 새 전체 저장소 검증이나 모델 비교가 아니다.

v15는 소스·실행기·계획·설정·원료·규칙과 모든 비용 상한 검사를 통과했다. `CHEMBL4247-query-2`에 남은 정확한2경로에는 모두 저장된 외부 단계 불일치가 있고, `CHEMBL3334418-query-1`의 동일6경로도 모두 저장된 완료 불일치다. 따라서 같은 전방 근거 아래 미평가 경로를 모두 낙관적으로 보아도 지지 입력 상한은4개다. 이는 새 실제 비교 성적이나 화학적 불가능성 주장이 아니며, 추가 모델/3D 실행 없이 이 정책을 기각할 근거다. 실제 주 지표는 기존4/12개로 유지했다.

**다음 고정 진단 — 다음 반응 작용기의 원료 쪽 연결:** 현재 `_nearest`는 내부 반응의 각 원료를 독립적으로 선택하고, 생성된 중간체가 외부 반응의 역할을 만족하는지는 이후 `_compatible_inner`에서 검사한다. 역반응의 원자 출처가 SMILES로 저장되기 전에, 외부 역할의 특정 매칭이 어느 내부 원료 힌트로 이어지는지 유한한 범위에서 기록한다. 한 원료에 온전히 남은 매칭, 여러 원료에 걸친 매칭, 반응 중심에서 바뀐 매칭, 대응 미확인을 구분한다. 역반응 힌트의 부위가 한 원료에 있었다고 해서 모든 유효한 실제 원료에도 그 부위가 반드시 있어야 하는 것은 아니다. 다른 원료나 새 결합에서 역할이 생길 수 있으므로 원료를 화학적으로 부적합하다고 일괄 제외하지 않는다. 활용한다면 기존 방문 풀·첫 선택·top2 예약을 유지하는 두 번째 후보 선호 정책으로만 먼저 고정 대조하고, 모호한 대응은 기존 선택으로 복귀한다. 새 정책은 아직 구현하거나 실행하지 않았다.

**원시 원자 출처 진단 완료 — 실제 검색 힌트와의 연결은 다음 단계:** [고정247문맥 진단](../benchmarks/results/synthesis-route-development-20261023/continuation-role-origin-control-v1.json)을 한 번 실행했다. 원시 역반응 결과451건 중 한 원료 내 국소 보존235건, 여러 원료로 분산20건, 한 원료 내 변경40건, 미확인156건이었다. 미확인은 역할 매칭 모호56건·부모 질의에 역할 없음100건이다. 원시 결과4개 상한에 도달한34문맥은 추가 대응의 존재 여부가 미확인이다. 역반응 호출247회·구조 작업 단위47,199를 기록했고 카탈로그 검색·전방 모델·3D 호출은 없었다. 구조 작업 단위는 실제 CPU 비용이나 부분구조 검색 연산 횟수가 아니다. 소스·설정·자료의 전후 해시와 결과에 대한 독립 검토를 통과했다.

초기 진단 커밋 `6e94953`의 `continuation_role_origin`은 당시 생성·선택 코드에서 호출하지 않는 함수였다. 해당 커밋은 기존 실행 로직의 AST가 변경되지 않았음을 확인했고 경로 집중 테스트48개와 Ruff 검사를 통과했다. 대칭·복수 매칭, 입체 대응 미확인, 출처 누락, 크기·작업 상한을 미확인으로 남긴다. 원시 결과만으로는 정규화·중복 제거한 실제 guide tuple이나 구체 카탈로그 원료에 이 출처를 연결할 수 없어 아래 후속 대조를 수행했다. 두 진단 모두 후보 생성 개선이나 경로 지지 증가로 세지 않으며, 실제 주 지표4/12개와 P1 미완료 상태는 유지한다.

**정규화 검색 힌트 연결 대조 완료:** 이어서 명시적 `diagnose_continuation` 모드를 구현하고 [기존 커밋/진단 끔/진단 켬의 고정 대조](../benchmarks/results/synthesis-route-development-20261023/continuation-guide-bridge-control-v1.json)를 실행했다. 전체12입력·247문맥에서 guide tuple·순서·quality, 기존 작업 카운터, reverse 캐시와 캐시 기반 center 조회가 같았다. 역반응 시도는 각 arm207회(합계621회)였고, 메타데이터를 얻기 위한 추가 역반응은 없었다. 정규화 전 동일 Mol의 원자 출처를 보관하고 같은 guide로 합쳐진 모든 관찰 대응을 확인했으며, 부분 수집·원시 결과 상한·입체/대칭 모호·정규화 부위 변경은 미확인으로 남겼다.

실제 guide 관찰357건 중84건은 원래 역할의 동일 위치가 한 정규화 원료 힌트에 남아 있음을 확인했고273건은 미확인이었다. 기존에 사전 공급이 없던 `CHEMBL4869-query-1/query-2`, `CHEMBL3864-query-2`에도 각각6·5·11건의 연결 가능한 힌트가 있었다. 이는 구체 원료나 새 경로의 성공 수가 아니다. snapshot 시도325회·구조 작업 단위63,060을 별도 계량했고, 복사 실패도 선차감하며 원료/생성물/모델/3D 계산은 실행하지 않았다. 경로 테스트51개·계량 테스트19개, Ruff와 코드/실행 결과 독립 검토를 통과했다. 전체 저장소 검증은 아니다. 현재 진단은 기본 비활성이고 원료 선택은 바꾸지 않는다.

**두 번째 원료 선호 정책 — 실험 구현·집중 검증 완료:** 연결이 확인된 내부 원료 slot에서만 기존 방문 풀의 ordinary 두 번째 원료를 다시 고른다. 원래 순위 순서에서 다음 외부 반응의 전체 역할과 명확한 입체 조건을 만족하는 첫 원료를 선호하되, 기존 첫 선택·anchor 예약·top2를 유지한다. 기본 검색/순위 캐시와 외부 역할별 최종 선택 캐시를 분리하고, 다른 외부 역할이 요청돼도 카탈로그 검색을 반복하지 않는다. 순위 보관은 검색당65,536행, 추가 역할 검사는 질의당8,192회·검색당65,536회, 역할 질의는16개·최종 문맥 캐시는128개로 제한한다. 저장 순위가 없거나 불완전하거나 예산·입체 대응이 미확인이면 원래 두 번째 원료를 유지한다. 실제 중간체 역할 검사와 전체 감사·원 입력 관문은 그대로 둔다.

[구현 검토 기록](../benchmarks/results/synthesis-route-development-20261023/continuation-second-preference-review-v1.json): 경로 테스트54개·계량 테스트19개와 Ruff, 독립 코드 검토를 통과했다. 작은 실제 규칙 재생 fixture에서 첫 원료를 유지하고 두 번째 원료를 바꿨을 때 다음 역할에 맞는 중간체가 생성됨을 확인한 뒤, 아래 전체12입력 대조를 완료했다. `RouteFirstSearch(prefer_continuation_second=True)`로만 켜는 기본 비활성 실험 구현이며 아직 workflow 설정에 연결하거나 P1 개선안으로 채택하지 않았다.

**전체12입력 v16 완료 — 공급 증가 확인, P1 채택 기준 미달:** [동결한 off/on 대조 결과](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v16.json)는24개 실행 모두 정상 종료했다. off는 v14의 생성물56개·정확 경로59개를 재현했고, on은58개·65개였다. 기존 생성물·경로는 모두 보존됐으며 새 생성물2개는 `CHEMBL4630839-query-1`에서 나왔다. 1단계 경로24개는 유지됐고2단계 경로는35→41개였다. 기존 qualified 생성물·정확 경로3개도 보존됐으나 이번에 qualification을 다시 평가한 것은 아니다. 사전 통과 입력 수는6/12개로 같았고 새 입력 확보는0개다.

정확한 기존 그래프/단계/생성물에 저장된 전방 근거를 연결하면, 미평가 경로를 모두 낙관적으로 보아도 지지 가능한 입력의 조건부 상한은5개다. 기준선5개 초과라는 P1 조건에 미달하므로 전체 모델/3D 비교를 반복하지 않는다. 이는 실제 지지가5개로 늘었다는 측정이나 화학적 불가능성 주장이 아니다. 실제 주 지표는4/12개로 유지한다. 정책은 공급 증가를 확인한 기본 비활성 실험 기능으로 보존한다.

전체12검색에서 두 번째 원료 교체19회, 추가 역할 검사422회·일치41회·입체 부적합12회·입체 미확인0회였다. 보관 순위102,247행, bridge snapshot 시도322회·구조 작업 단위62,119·역할 문맥357건은12검색 합계이며 각 검색의 상한을 별도로 확인했다. 소스·실행기·계획의 전후 바인딩, 입력/설정/자산 바인딩, off 동일성 및 분석 결과의 독립 검토를 통과했다. 검색 FP 상한65,536은 검색 계량 범위이며 기존 관찰·최고 점수 보고용 FP는 별도 진단 작업이다. 입력별 후보 수가 달라 추가 FP 횟수가 같다고 주장하지 않는다. 시간은 공유 카탈로그 로드를 제외한 순차 off/on 측정으로 속도 개선의 인과 근거가 아니다.

**다음 우선 진단 — 입체 anchor와 다음 반응 역할의 동시 충족:** `CHEMBL4869-query-1/query-2`, `CHEMBL3864-query-2`는 두 번째 원료를 각각2·2·3회 바꿨으나 최종 anchor 통과가 모두0개였다. 기존 v14의 완전한 카탈로그 색인에서 두 anchor query의 일치 수는 각각[42,0], [0,42], [0,0]이고 posting 절단은 없었다. 다만 완성된 anchor query가 없다는 사실만으로 결합 반응을 통해 그 문맥을 만들 수 없다고 단정할 수 없다. 저장된 생성물·경로와 필요한 원료 행만 사용해 어떤 anchor가 소실됐는지, 고리/입체 core 자체가 없는지, 추가 결합으로 만들 수 있는 주변 문맥이 부족한지, 원료/조합 선택에서 놓쳤는지를 분리한다. 원래 anchor를 통과하지만 극성·유사도 등에서 탈락한 `CHEMBL5163-query-1`, `CHEMBL3864-query-1`은 별도 원인으로 둔다. 이 구분 전에 새로운 순위 조절이나 전체 모델 실행을 추가하지 않는다.

**계속 필요한 선택성 근거:** 단일/다중 치환, 보호기·당량·시약·조건의 출처를 정확한 단계에 연결한다. 원료·조합 선택 변경은 원 입력 유사도·극성·입체 보존과 기존 예산 안에서 검증하고, 조건/당량이 없는 선택적 반응을 확인된 경로처럼 표시하지 않는다. 현재 모델이 지원하지 않는 온도·시간 입력을 추가한 것만으로 지지되었다고 판정하지 않는다. 아직 경로가 공급되지 않는6입력의 원인 분해도 유지한다.

**검증 도구의 재발 방지:** 실행용 설정을 일부 필드만 복사하면 qualified 모드·refinement 같은 필수 조건이 빠질 수 있다. 저장된 전체 유효 설정을 바이트/내용 해시로 연결하고, 모든 입력의 설정 검증을 카탈로그·모델 로드 전에 실행한다. 중단 결과도 마지막 체크포인트와 별도 실패 기록을 남기며, 수정 실행은 새 버전에 보존한다.

가설마다 **고정된 작은 대조 → 독립 검토 → 전체 패널 사전 진단 → 필요한 실제 비교** 순서를 따른다. 실패한 대조는 보존하고 해당 가설을 종료한다. 한도 확대나 관문 완화가 필요하면 별도 정책으로 제안하며 현재 P1의 성공 조건을 사후 변경하지 않는다. 구현은 `gpt-6-sol` medium, 검토는 Astra로 역할을 유지한다.

## 실제 비교 결과와 진단 근거

**최신 실제 결과와 다음 순서:** [비교·손실 진단 기록](../benchmarks/results/synthesis-route-development-20261023/actual-comparison-v2.json)의 12개 입력 모두 정상 종료했고, 저장 경로를 독립 재생·감사한 결과 전체 단계의 전방 지지가 있는 생성물은 8개, 경로는 9개였다. 기준선은 69개 생성물·304개 지지 경로·5개 입력이다. 새 결과의 사전 경로 공급은 v13과 정확히 같은 52개 생성물·55개 경로이므로, 사전 통과 6개에서 실제 지지 4개로 줄어든 원인을 생성 이후 단계에서 찾는다. 최종 qualified 3개는 모두 `CHEMBL4630839-query-1`의 2단계 경로이며 원 입력 기준 지문 유사도 0.672–0.694, 선택된 pose의 형태 유사도 0.912–0.918을 가진다. 중심 pyrimidine은 유지하고 주변 pyrrolidine을 methoxy/methylthio로 바꿨으며, 하나는 다른 말단 고리 크기도 바꿨다. 기존 Murcko scaffold 변경 정의는 충족하지만 새로운 중심 헤테로고리 교체 성과로 표현하지 않는다. `custom_unvalidated` 설정에서 얻은 개발 패널 결과다.

**확인된 불일치:** `CHEMBL4247-query-2`의 두 경로에서 모델은 의도한 aryl-Cl 치환 대신 aryl-Cl을 남긴 carboxamide를 첫 예측으로 반환했다. 다른 경로는 내부 biaryl 생성 단계가 불일치했다. `CHEMBL3334418-query-1`의 두 생성물은 같은 원료 쌍의 regioisomer이며, 하나만 연결되지 않은 조각과 입체 표기를 모두 제거한 진단용 비교에서 가까운 구조가 나왔다. 원래 예측은 정확한 입체 생성물과 다르고 추가 조각도 있으므로 여전히 불일치다. 이 두 입력에서 호출·토큰 한도 소진은 관측되지 않았다. 반응 조건 부재, 경쟁 부위, 모델 학습 범위 중 무엇이 원인인지는 아직 분리되지 않았다. 진단용 정규화를 실제 승인 관문에 적용하지 않는다.

**원료 선택 관찰과 기각한 수정안:** [두 입력의 검색 기록·고정 대조](../benchmarks/results/synthesis-route-development-20261023/actual-v2-explicit-fallback-retrieval-control-v1.json)에서 기존 생성물·경로·작업 카운터를 모두 재현했다. 112개 고유 검색 문맥·159,939개 순위 행을 누락 없이 보존했다. `CHEMBL3334418-query-1`의 명시적 대체 검색은 대응하지 않는 역할에 `C`를 임시 질의로 사용한다. 선택된 알코올과 이 질의의 0.05556 지문 유사도는 서로 다른 Morgan 특징이 2,048비트 지문의 같은 위치로 접힌 충돌에서 나왔다. 그러나 두 번째 원료를 같은 방문 풀의 최소 원자수 원료로 바꾼 대조는 새 통과 생성물을 하나도 만들지 못했다. 유사도·극성 기준을 유지했으며 이 수정안은 기각했다. 후속 고정 대조에서 해당 임시 질의의 두 번째 원료만 원 입력 지문으로 선택하는 정책을 검증했다. 기존 첫 선택·역할·anchor 예약·방문 풀·전체 관문은 유지하고, 결과를 보기 전에 최고 후보 하나를 고정했다. 이 변경은 실험 브랜치의 명시적 route-first 구현에 반영됐고 집중 테스트 69개를 통과했으나, 후속 신규4경로 전방 대조에서는 모두 불일치했다. `CHEMBL4247-query-2`에는 같은 명시적 임시 질의가 없어 이 수정안만으로 두 입력을 함께 해결한다고 주장하지 않는다.

### 실제 비교 전의 수정·사전 검증 이력

**최신 v13은 실제 모델 비교 진입 조건을 충족했다:** [고정 12입력 결과](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v13.json)는 정상 종료했고 소스·실행기·관문·설정 바인딩 검사를 통과했다. 사전 통과 입력은 **6/12개**, 고유 입력/생성물 쌍 **52개**, 경로 **55개(1단계 20개·2단계 35개)**다. v12의 모든 통과 생성물 집합을 유지했고, 예산 문제로 평가하지 못했던 `CHEMBL4247-query-1`에서 대기 생성물 66개를 모두 검사해 생성물 11개·2단계 경로 14개를 얻었다. 이 입력의 총 지문 계산은 63,567회(초기 hit 1·생성 63,487·최종 순위 65·callback 14)로 기존 65,536회 이하였으며, 전체 12입력에서 순위 미계산·callback 미시도 후보는 각각 0개였다. 전체 테스트와 현재 소스·자산·실행 조건 동결을 마친 뒤 실제 전방 모델·3D 비교를 진행한다. **6개는 진입 조건이며 P1 완료나 전방 지지 성과가 아니다.**

**v12에서 확인한 회귀:** [고정 12입력 실행](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v12.json)은 정상 종료했고 소스·실행기 해시와 기존 관문·설정이 유지됐다. 사전 통과 입력은 **4→5개**, 고유 입력/생성물 쌍은 **35→41개**, 경로는 **40→41개(1단계 20개·2단계 21개)**다. `CHEMBL4630839-query-2`에서 1개, `CHEMBL4247-query-2`에서 2단계 생성물 4개를 새로 얻었다. 이 네 생성물은 조사에 사용한 저장 성공 생성물들과 다르다. 반면 `CHEMBL4247-query-1`은 5→0개로 줄었다. 이 입력에서는 생성 작업 120건이 기록됐지만 지문 계산 65,536회를 검색·순위 계산에서 소진해 최종 생성물 검사·경로 감사가 0건이었다. 120건은 중간체를 포함한 생성 작업 수이며, 고유 최종 생성물 수가 아니다. 이 회귀를 지문 예산 분리로 수정한 결과가 위 v13이다.

최종 후보 평가에는 전체 지문 상한 안에서 `min(2 × max_products, max_fingerprint_calls // 2)`를 확보한다. 기본 설정에서는 2,048회이며 검색과 평가를 합친 상한 65,536회는 유지한다. 작은 예산에서는 새 지문 0/1회와 후보당 검사 최대 1회를 함께 감당할 수 있는 결정적 부분집합만 평가하고, 이미 통과한 후보의 경로 감사를 계속한다. 예산으로 미평가한 생성물을 화학적 탈락으로 세지 않는다. 이전 전역 소진 기록만으로 모든 대기 후보를 버리던 동작을 회귀 테스트로 막는다.

앞선 [v11 사전 관문 점검](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v11.json)은 12개 모두 정상 종료했고 실행 전후 소스·실행기·기존 감사 모듈 해시가 일치했다. 통과 입력 **4/12개**, 입력별 고유 생성물 합 **35개**, 경로 **40개(1단계 16개·2단계 24개)**로 v10과 같고 통과 생성물의 정확한 구조 집합도 같았다. 원료 입체 검사는 672회, 확정 탈락 원료 선택은 183건이었다(반복 조회를 포함한 결정 횟수). 생성물의 미지정 입체화학에 따른 첫 탈락 기록은 50건에서 14건으로 줄었지만 공급 범위는 확대되지 않았다.

앞선 [v10](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v10.json)은 예산 배분 수정으로 v9의 3/12개에서 4/12개로 확대했다. 새 `CHEMBL4247-query-1`에서 생성물 5개·2단계 경로 10개를 얻은 반면, 기존 `CHEMBL4630839-query-1`의 생성물 수는 34개에서 26개로 줄었다. v11의 원료 선별은 이 통과 결과를 그대로 유지한 것이며 추가 경로 성능 향상으로 표현하지 않는다.

**이 수치는 원래 입력의 사전 관문과 전체 경로 재생·감사를 통과한 공급량이다. 전방 모델·3D·최종 qualification 결과가 아니며 실험 합성 가능성을 입증하지 않는다.** v13에서 상한이 6개로 확대돼 실제 비교에 진입할 수 있게 됐지만, 고정된 기준선 5개 초과 조건은 모든 단계의 실제 전방 지지로 입증해야 한다. P1의 채택·develop 병합은 그 결과까지 보류한다.

확인된 진전은 **외부 경로 계획 사이의 실제 검색 기회 확대**다. v9에서 첫 계획만 원료를 조회하던 입력들의 후순위 계획에도 v10에서는 조회가 배정됐다. 그러나 남은 8개 입력 중 4개는 생성물의 입체 anchor 대응을 하나도 보존하지 못했고, 다른 입력들은 물성·극성·미지정 입체화학에서 탈락했다. 따라서 다음 작업은 남은 예산 편중과 원료→중간체→최종 생성물의 입체·특징 손실을 분리해서 진단하는 것이다. 이전 극성 원료 순위화 [v8](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v8.json)은 통과 입력을 2/12개로 줄여 되돌렸으며 다시 채택하지 않는다.

| P1 — 채택 판단 | **모든 단계의 전방 지지 확인.** 사전 통과 입력이 6개 이상일 때 실행 계획·소스·자산·작업 상한을 고정하고 실제 전방 모델과 기존 3D/qualification을 실행한다. | 기존 주 지표인 **변경 scaffold의 정확한 생성물에 대해 전체 경로 감사와 모든 단계의 전방 지지가 있는 입력 수 > 5/12**를 충족해야 한다. 6개 사전 통과는 실행 진입 조건일 뿐 완료 조건이 아니다. 최종 qualified 결과는 별도로 보고한다. |
| P2 — P1 이후 | **다단계 연결·대체 경로와 근거 예산.** 재사용 가능한 중간체와 같은 최종 생성물의 대체 경로를 관리하고, 경로 전체의 의존성과 단계별 평가 상태를 보존한다. | 누락·불일치 중간체, 순환, 부분 경로 승인을 거절한다. 마지막 단계만 맞는 경로는 전체 지지로 세지 않는다. 일반 다단계 확장은 P1의 최대 2단계 변경과 분리한다. |
| P3 — 근거 확장 | **실제 합성 검토에 필요한 정보.** 반응 조건·시약·문헌 사례·보호기와 선택성 검토, 원료 공급사 식별자·조회 시점을 정확한 구조와 단계에 연결한다. | 확인된 출처와 미확인 항목을 구분한 후보별 경로 검토 자료를 만든다. 원료 등재를 구매 가능성으로, 모델 일치를 수율·실험 성공으로 표현하지 않는다. |
| 후속 독립 평가 | **다양한 입력에서 재현성 확인.** 현재 패널의 수정이 끝난 뒤 개발에 쓰지 않은 scaffold 계열로 입력을 분리하고 동일 비용의 기존 방식·변경 요소별 비교를 설계한다. | 입력별 경로 보유율, 정확한 고유 생성물 수, 1/2단계 분포, 유사도·입체 보존, 미평가율·시간·모델 비용을 함께 공개한다. 현재 12입력의 반복 개발 결과를 독립 검증으로 부르지 않는다. |

이미 수정한 항목은 입체 anchor 표현, 원료 검색 색인, 원 입력 기준의 조기 후보 선별, 감사 불가능 템플릿 사전 제외, 역반응 원자 출처 분할, 다음 반응에 부적합한 중간체의 beam 진입 방지다. 이들은 구현·단위 검증의 진척이며, P1 채택 성공과 구분한다. 진행 중 코드는 `feat/route-first-generation`에 보존하고, 성능 기준을 충족하기 전에는 `develop`의 개선 기능으로 병합하지 않는다.

후속 실험은 **가설·수정 → 제한된 테스트·검토 → 소스 고정 → 통합 실행 → 저장 결과 분석** 순서로 진행한다. 이미 저장한 경로를 조사하기 위해 카탈로그를 반복 로딩하지 않도록 통과 경로와 가까운 탈락 경로를 함께 보존한다. 실행 중 소스는 바꾸지 않으며, 실패·중단된 실행도 새 실행과 구별해 남긴다.

## P1 실제 비교에서 확인한 문제와 수정 순서

[첫 비교의 추적 기록](../benchmarks/results/synthesis-route-development-20261023/route-first-v1.json)은 12개 모두 정상 종료했고 시간초과·실행 오류는 없었다. 새 방식은 지지된 고유 입력/생성물 쌍 0개, 기준선은 69개였다. 새 방식에서 5개 입력의 후보 15개가 후속 intake에 들어갔지만 원 입력의 bit 유사도·극성 특징 수용량·물성 관문에서 모두 탈락해 전방 예측과 3D 평가까지 도달하지 못했다. 나머지 7개 입력은 입체 대응 관문 등을 통과한 경로 후보를 공급하지 못했다. 따라서 생성된 경로 수만으로 개선을 주장할 수 없다.

| 순서 | 관측 문제 | 수정 및 확인 기준 |
|---|---|---|
| P1a | 작은 고정 반경에서 서로 다른 치환기가 같아 보이면 원 입력 자체의 지정 입체화학도 표현하지 못한다. | 원 입력만 사용해 필요한 범위까지 입체 anchor를 확장·컴파일한다. 자체 대응이 유일하고 입체 표기가 유지될 때만 사용한다. 반전, E/Z 소실, 모호한 대응, 서로 다른 중심의 중복 대응은 계속 거절한다. |
| P1b | 입력 구조와 무관한 결정적 해시 순서로 카탈로그를 줄였고, 실제 생성물의 유사도·물성은 낮았다. 적합한 원료를 검색에서 놓쳤는지, 카탈로그 자체에 없는지는 아직 구분되지 않았다. | 한 번 만든 크기·헤테로원자·방향족·고리 특성 색인으로 검색 범위를 좁히고, 실제 반응성 역할과 구조 지문으로 원료를 순위화한다. 역반응 SMARTS의 불완전한 구조는 검색 힌트로만 사용하며 구체 원료·정방향 규칙·경로 감사의 근거로 사용하지 않는다. |
| P1c | 유사도·물성에서 탈락할 제품이 제한된 설계 3개 자리를 차지한다. | 기존 원 입력 bit 유사도, 물성, 극성 수용량, scaffold·stereo 관문을 intake 전에 동일하게 적용한다. 제한된 전체 생성물 중 통과 제품을 품질 순으로 선택한다. 2단계 탐색 예산은 보존하되 낮은 품질의 제품을 단계 수만으로 강제 채택하지 않는다. |
| P1d | 기존 엄격한 원자 출처 감사에 통과할 수 없는 규칙도 제한된 검색 자리를 차지하며, 상위 규칙을 찾은 뒤에도 전체 규칙을 반복 확인한다. | 기존 `template_maps` 검사를 재사용해 원자 출처 누락·충돌이 있는 규칙을 검색 전에 제외한다. 규칙 검사 예산에 이 작업도 청구한다. 2단계 내부 검색은 기존 우선순위의 상위 규칙을 찾으면 확인을 끝내고 남은 예산을 다른 전구체에 사용한다. 실제 생성물의 전체 감사는 계속 수행한다. |
| P1e | 구현이 돌아가는 것과 합성 근거를 갖춘 후보를 더 많이 공급하는 것은 다르다. | 작은 양성·음성 fixture와 실제 카탈로그의 모델 없는 가능성 점검 후, 소스·설정·예산을 다시 고정해 새 12입력 실행을 한다. 각 단계의 정확한 전방 예측과 전체 경로 audit까지 통과한 입력 수가 기준선 5개보다 증가해야 개선으로 채택한다. |

v2 정책은 `catalog-rule-route-first-v2`로 구분한다. 원료 색인 250,000행, 질의당 8,192행, 누적 방문 262,144회, 지문 계산 65,536회, 조합 512개, 생성물 1,024개, 경로 감사 시도 64회, 최대 2단계와 기존 모델·3D 예산을 유지한다. 소진·미평가·화학적 불일치를 분리한다. 첫 실패 결과를 보고 같은 개발 패널에서 수정했으므로 후속 비교도 독립 검증이나 홀드아웃 결과로 부르지 않는다. 합성 조건·수율·실물 원료 구매 가능성은 P3 근거가 없으면 계속 미확인이다.

**v2 모델 실행 전 점검:** [실제 카탈로그·기존 사전 관문을 적용한 12입력 진단](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v1.json)에서 후보 공급은 2/12개 입력이었다. 각각 6개와 2개의 감사된 생성물이 있었고 모두 1단계였다. 전방 예측·3D를 실행하지 않았으므로 지지·qualified 결과가 아니다. 이 공급량으로는 주 지표가 최대 2/12개여서 채택 조건을 달성할 수 없다. 따라서 비용이 큰 비교는 실행하지 않고, 보존해야 하는 입체 부분구조가 카탈로그에 있는지와 2단계 검색 예산이 어느 전구체에 사용되는지부터 확인한다. 카탈로그에서 anchor가 없다는 사실만으로 2단계 조립 불가능을 단정하지 않는다. 이 진단 소스에서 발견한 질의당 행 수 상한의 +1 경계 오류도 다음 실행 전에 수정한다.

[입체 부분구조의 카탈로그 존재 여부 진단](../benchmarks/results/synthesis-route-development-20261023/route-first-anchor-availability-v1.json)에서는 `CHEMBL4630839-query-2`, `CHEMBL4247-query-1`, `CHEMBL5163-query-1`의 국소 입체 anchor를 포함한 원료가 각각 8개, 412개, 310개 확인됐다. 따라서 해당 anchor를 포함하는 전구체 질의에서 이 원료를 검색 풀 안에 보존하는 것이 다음 수정 대상이다. 반응성 역할 적합성과 전체 경로 성공은 아직 확인되지 않았다. 추가 색인 비교 횟수·보존 목록 크기를 명시적으로 제한하고 기존 질의당 행 수 안에서 처리한다. 이 진단은 모델 성능 비교가 아니며, 두 입력에서 단일 원료에 없는 anchor를 발견한 결과도 다단계 합성 불가능의 증거로 해석하지 않는다.

입체 부분구조 색인의 추가 작업 상한은 입력에서 선택한 anchor 2개, 전체 색인 비교 500,000회, anchor별 원료 목록 256개, 전구체 질의의 anchor 확인 2,048회다. 이는 기존 행 수·지문·시간 상한 안에 추가하는 명시적 작업이며 이전 버전과 CPU 작업량이 같다고 주장하지 않는다. 목록 절단·미완성 색인은 따로 보고하고, 후속 실제 비교 실행 계획에도 이 상한을 고정한다.

**입체 원료 검색 반영 후:** [수정된 실행기로 완료한 12입력 진단](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v3.json)에서도 공급은 2/12개 입력, 모두 1단계에 머물렀다. 일부 입력에서 입체 anchor를 보존한 생성물이 늘었지만 유사도·극성·물성 관문까지 함께 통과하지 못했다. 9/12개 입력은 반응 규칙 확인 512회 상한에 도달했다. 다음 단계는 가장 가까운 탈락 생성물의 정확한 경로·원료·이유를 확인하고, 동일 우선순위의 상위 규칙을 이미 찾은 뒤에도 모든 규칙을 확인하는 2단계 검색의 중복 작업을 줄이는 것이다. 기준 완화나 모델 비교 재실행으로 이 실패를 덮지 않는다. 중간 진단 한 건은 새 anchor 옵션을 전달하지 않은 실행기 오류로 중단·제외했으며, 수정된 진단은 모든 입력의 활성 anchor 수를 확인했다.

[반응 템플릿의 원자 출처 점검](../benchmarks/results/synthesis-route-development-20261023/route-template-eligibility-v1.json)에서는 91개 중 26개에 기존 엄격 감사가 허용하지 않는 출처 누락 또는 매핑 충돌이 확인됐다. 이는 해당 화학 반응 자체가 불가능하다는 뜻이 아니라 현재 템플릿만으로 생성물 전체 원자의 출처를 입증하지 못한다는 뜻이다. 이 규칙을 미리 제외하면 검증 가능한 다른 경로를 탐색하는 데 제한된 예산을 사용할 수 있다. 규칙 자산이나 감사 기준을 조용히 바꾸지 않는다.

**규칙 사전 검사·내부 탐색 수정 후:** [12입력 진단](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v4.json)에서도 공동 사전 관문을 통과한 공급은 2/12개, 고유 생성물 8개, 모두 1단계였다. 규칙 사전 검사 91회와 입력별 반응성 확인을 합쳐 기존 512회 상한 안에서 수행했다. 구현의 정확성과 예산 처리는 확인했지만 채택 조건은 여전히 충족하지 못했다. 가장 가까운 탈락 생성물의 정확한 구조·원료 ID·경로도 저장했다. 다음 진단은 원료의 입체 부분구조 존재와 실제 필요한 반응 부위의 사용 가능성을 구분한다. 보호된/치환된 질소만 있는 경우를 검색 실패와 혼동하지 않으며, 규칙·원료 확장이 필요하다는 근거가 나오면 자산 변경을 별도 요인으로 명시한다.

[반응 부위까지 확인한 원료 진단](../benchmarks/results/synthesis-route-development-20261023/anchor-ring-nitrogen-v1.json)에서 위 세 입력의 anchor를 유지하는 자유 고리 NH 원료가 각각 4개, 213개, 163개 확인됐다. 기존 아릴/헤테로아릴 결합 규칙의 해당 역할도 일치하므로 단순 원료 부재 가설은 지지되지 않았다. 반응 상대 원료와 전체 경로의 성공은 별도 검증이 필요하다. 다음 수정은 역반응 힌트의 원자 출처 분할이다. 일부 역반응은 입력의 같은 원자를 여러 전구체에 중복 복제해 제한된 검색 자리를 차지한다. 입력 원자가 각 전구체에 정확히 한 번씩 배치되는지 확인한 뒤 검색 힌트를 선택하고, 실제 카탈로그 원료의 정방향 재생·전체 경로 감사는 계속 별도로 수행한다. 이는 검색 힌트의 품질 제한이며 제외한 화학 반응 자체의 불가능성을 주장하는 규칙이 아니다.

**역반응 검색 힌트 수정:** 원 입력 원자의 중복·누락·잘못된 출처를 가진 역반응 결과를 직렬화 전에 제외한다. 추가로, 정상적인 `042`/`045` 규칙의 힌트가 원자 `*`와 템플릿이 강제한 수소 표기 때문에 실제 분자 검사를 통과하지 못하던 문제를 확인했다. 원자 출처 분할 확인 후 복사한 **검색 힌트에서만** 출처 없는 말단 임시 원자를 제거하고, 제한된 템플릿 수소 표기를 처리한다. 실제 카탈로그 원료·규칙·생성물은 수정하지 않는다. 입체중심이나 E/Z 참조를 손상하는 편집은 거절한다. 작은 실제 규칙 점검에서 `042`/`045`의 힌트가 각각 2개 생성되고 8개 검색 계획 안에 진입했다. 이는 검색 도달성의 수정이며, 실제 카탈로그 조합과 전방 지지 성과는 후속 12입력 진단으로 확인한다.

[힌트 수정 후 12입력 진단](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v5.json)은 사전 관문을 통과한 입력이 2개에서 3개, 고유 생성물이 8개에서 10개로 증가했다. 경로는 12개이며 모두 1단계다. 기준선 초과 조건은 아직 충족할 수 없어 모델·3D 비교를 실행하지 않았다. 2단계 탐색에서는 다음 반응의 원료 역할을 충족하지 못하는 중간체가 유사도만으로 제한된 beam에 남을 수 있음을 작은 재현 사례에서 확인했다. 해당 역할과 입체 조건을 먼저 확인한 뒤 순위화하도록 수정하며, 기존의 실제 아미드 2단계 양성 경로 검증을 유지한다. 정체성 반응을 사용한 별도 beam 재현 사례는 탐색 결함을 분리하는 단위 테스트이고 실제 합성 양성 사례로 세지 않는다.

**중간체 역할 선별 후:** [12입력 진단](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v6.json)은 중간체 684개를 확인해 604개를 다음 반응에 부적합한 것으로 제외했지만, 사전 관문 통과 입력은 3/12개로 유지됐다. 통과한 고유 생성물 10개와 경로 12개는 모두 1단계다. 일부 2단계 생성물은 만들어졌으나 입체화학·유사도·극성 관문에서 탈락했다. 따라서 **P1은 아직 완료·채택되지 않았다.**

v7에서 수정한 대상은 [검색 힌트의 반응 부위 보존](../benchmarks/results/synthesis-route-development-20261023/outer-guide-role-v1.json)이다. 선택된 외부 검색 계획 93개 중 92개에서 하나 이상의 힌트가 해당 반응물 역할에 맞지 않았다. 예를 들어 임시 원자 삭제 후 아릴 할라이드 힌트가 아릴 수소 구조로, 산/아실 유도체 힌트가 알데하이드로 바뀐다. 힌트 자체가 실제 반응물이라고 주장한 것은 아니지만, 특히 2단계 탐색 목표에서 다음 반응에 필요한 부위를 잃을 수 있다. 원래 반응물 SMARTS가 허용하는 제한된 대표 원자를 사용해 반응 부위를 보존하는 질의를 만들고, 원자 출처·원소·입체화학·쿼리 역할을 확인한다. 실제 원료와 생성물을 고치는 방식으로 대체하지 않는다.

이 수정에서는 **정확한 반응물 역할을 만족하는 질의만 강제하지 않는다.** 국소 시제품에서 그렇게 제한하면 기존의 유효한 scaffold 후보를 찾던 근사 질의도 사라졌다. 따라서 원시 역반응 결과 하나당 질의 묶음 하나만 유지하되 역할을 만족하는 질의가 있으면 사용하고, 구성 실패·예산 소진 시에는 기존 출처·입체 안전 검사를 통과하는 근사 질의를 유지한다. 명시적 대체 검색은 별도 표기한다. [국소 시제품의 12입력 점검](../benchmarks/results/synthesis-route-development-20261023/route-query-hybrid-prototype-v1.json)에서는 기존과 같은 검색 계획 93개 중 역할 대응 14개, 근사 71개, 명시적 대체 8개를 보존했다. 이는 **카탈로그·전방 모델 없이 확인한 검색 계획 구성 결과**이며 경로 공급이나 합성 성능의 개선 증거가 아니다. 후속 구현은 관련 회귀·telemetry 테스트 47개와 독립 코드 검토를 통과했다. 시간 제한 이후 암묵적 대체 검색으로 진입하던 오류도 회귀 테스트와 함께 수정했다. 실제 카탈로그를 사용하는 v7 통합 진단도 아래와 같이 완료했으며, 전방 모델·3D 성과와 구분한다.

추가 질의 구성 비용은 전구체 한 부분에 대한 대표 원자 구성·역할 검증 시도를 한 단위로 센다. 임시 원자가 없는 부분의 검증도 포함해 원시 결과의 모든 부분에 걸쳐 최대 16회, 한 탐색당 누적 1,024회로 제한한다. 시도 한 번당 역할 대응은 한 번만 열거하며 최대 65개로 제한한다. 65개에 도달하면 열거가 잘렸을 가능성이 있어 정확한 역할 대응 승인을 거절한다. 대표 원자는 중성을 우선하고 원자 번호 순으로 선택하며, 허용되는 경우 산에는 OH, 해당 아릴 규칙에는 F 또는 Cl이 먼저 선택된다. 원래 입력에서 유래한 원자의 원소·동위원소·전하와 유지되는 입체정보를 보존하고, 원래 매핑 또는 국소 임시 태그의 모든 역할 위치가 일치해야 정확한 역할 질의로 표시한다. 검사한 분자 자체를 직렬화하며, 대응 누락이나 다른 부위의 우연한 일치는 승인하지 않는다. 이 추가 구성 비용은 기존 카탈로그·지문·조합·생성물·경로·모델·시간 상한과 별도로 계수하고 실제 비교 전에 고정한다. 기존 상한이 같다는 이유로 총 CPU 작업량도 같다고 주장하지 않는다.

**반응 부위 보존 후 통합 결과:** [v7 진단](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v7.json)은 12개 모두 정상 종료했고 실행 전후 소스·실행기 해시가 일치했다. 사전 관문 통과 입력은 3/12개로 유지됐고, 입력별 고유 생성물의 합은 10개에서 30개로 늘었다. 경로는 1단계 8개·2단계 22개이며, 2단계 경로는 모두 `CHEMBL4630839-query-1`에서 나왔다. 모든 통과 경로의 그래프·생성물·재생 검증과 감사 바인딩, 가까운 탈락 경로를 원본 결과에 보존했다. 전체 원자·입체 감사의 상세 보고서를 저장했다는 뜻은 아니다. 추가 질의 구성 작업은 입력당 최대 176회로 누적 1,024회 상한 안에 있었다. 전방 모델·3D는 실행하지 않았다. 전체 경로 지지 입력 수의 상한이 여전히 3개이므로 기준선 5개 초과 조건을 만족할 수 없고, P1은 계속 미완료다.

**극성 순위화 시도와 철회:** v7에서 입체 anchor를 보존한 후보 8개 중 6개가 극성 수용량에서 탈락하고 가장 가까운 후보의 유사도가 약 0.506이었던 것을 근거로, 두 번째 원료 선택에 전구체 질의와의 극성 특징 개수 거리를 도입했다. [v8 진단](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v8.json)은 12개 정상 종료·해시 일치를 확인했으나, 사전 통과 입력이 3개에서 2개로 줄었다. 입력별 고유 생성물 합은 30개로 같고 2단계 경로는 24개였지만 기존 `CHEMBL3334418-query-2`의 두 후보를 잃었다. 진단의 생성 시간 합은 약 322초에서 665초로 늘었다(일회 카탈로그 로딩을 제외한 관측 시간이며 무작위 시간 비교가 아님). 해당 입력에서는 극성 개수 거리가 3에서 1로 가까워진 대체 원료가 기존 두 경로에 공통인 원료를 밀어냈다. 전체 패널에서 이 시도는 두 번째 슬롯의 anchor 우선순위도 함께 바꾸었으므로 모든 변화를 극성 개수만의 효과로 해석하지 않는다. 구현 `6c4a5e7`을 `19110e4`에서 되돌렸고 유지하는 런타임은 v7과 동일하다. 최종 관문이나 기준선은 바꾸지 않았다.

[저장된 기준선 후보의 사전 관문 대조](../benchmarks/results/synthesis-route-development-20261023/baseline-pre-evidence-gates-v1.json)는 독립 경로 분석이 승인한 69개 입력/생성물 쌍의 구조와 해시를 확인했다. 카탈로그·모델·경로 재생을 다시 실행하지 않고 동일한 생성물 관문을 적용했을 때 27개가 3개 입력에서 통과했고, 42개는 국소 입체 anchor 대응에서 먼저 탈락했다. 이는 먼저 발견한 탈락 이유이며 그 42개의 나머지 관문을 모두 독립 검사한 결과가 아니다. 이 3개 입력을 새로운 채택 기준선으로 사용하지 않는다. 기존 주 지표 **전체 경로 지지 입력 >5/12**는 그대로다.

[저장 경로의 누락 지점 진단](../benchmarks/results/synthesis-route-development-20261023/saved-route-loss-v1.json)에서 `CHEMBL4247-query-2`의 관문 통과 생성물 두 개는 같은 원료·규칙 스냅샷의 규칙 `036→042` 경로를 갖지만 현재 검색에서는 나오지 않았다. 선택된 `042` 질의를 가정하면 `036`은 내부 규칙 순위 8위여서 4개 상한 밖이다. 이는 **조건부 내부 선택 제외**이며, 그 질의가 실제로 2단계 탐색에 진입했는지와 원료 풀 순위는 당시 기록으로 확인되지 않는다. 따라서 규칙 `036`을 올리는 것만으로 복구된다고 판단하지 않는다.

후속 [원 입력의 역반응 절단 부위 진단](../benchmarks/results/synthesis-route-development-20261023/reverse-center-audit-v1.json)은 더 앞선 계획 선택 문제를 확인했다. 고정 원시 결과 상한 4개 안에서 서로 다른 유효 결과 3개가 이미 생성됐다. 중앙의 두 질의는 실제 반응물 역할을 만족했지만, 역할을 만족하지 않는 주변부 근사 질의가 크기 차이 0이라는 이유로 선택됐다. 올바른 질의의 크기 차이 1은 필요한 이탈 원자 때문에 생긴 것이었다. `042/045/046/047`도 같은 주변부 절단에 자리를 반복 배정했다. 따라서 현재 수정은 규칙 ID별 한 자리 배정 대신 절단 부위의 다양성과 역할 적합성을 보존하는 것이다. 원시 결과를 더 생성하거나 알려진 성공 생성물·원료 ID를 검색의 초기값이나 예외 조건으로 넣지 않는다.

절단 부위 메타데이터는 이미 출처 분할 검사를 통과한 외부 역반응 결과에서만 계산하며, 검사한 원자·부모 결합을 합쳐 탐색당 32,768회로 제한하고 시간 제한도 확인한다. 메타데이터를 완성하지 못하면 해당 질의를 삭제하지 않고 부위 미확인으로 기록한다. 단일 전구체·절단 없는 경우·명시적 대체 검색은 빈 부위 하나로 합치지 않는다. 선택된 계획의 2단계 진입 여부, 내부 규칙 선택과 단계별 상태 수를 최대 8개 계획에 대해 기존 작업에서 기록한다. 이 수정은 계획 선택의 입증된 누락을 해결하기 위한 것이며, 중앙 질의가 실제 원료나 최종 통과 후보를 더 찾는지는 후속 통합 진단 전까지 미확인이다.

**현재 반응 부위 선택 수정의 검증 범위:** [계획 선택·후속 절단 점검](../benchmarks/results/synthesis-route-development-20261023/center-allocation-controls-v1.json), 관련 테스트 50개와 독립 코드 검토를 통과했다. 카탈로그 없이 계획 선택만 실행한 점검에서 중앙의 두 역할 적합 `042` 절단이 모두 외부 계획 8개 안에 남았다. 외부·내부 호출의 메타데이터 옵션 차이 때문에 같은 역반응을 중복 실행하던 캐시 오류도 회귀 테스트로 수정했다. 이 점검은 실제 원료 검색이나 후보 공급 성공을 검증한 것이 아니다.

**내부 선택 수정 전의 문제:** 당시 후속 점검에서 두 중앙 질의 모두 필요한 내부 규칙 `036`이 상위 4개 안에 들지 않았다. 해당 규칙을 가정해 고정 원시 결과 4개만 확인했을 때에도 필요한 방향족 고리 사이의 절단은 포함되지 않았다. 템플릿 부분구조 대응 순번을 실제 역반응 결과 순번으로 동일시하지 않으며, 상한을 올리면 해결된다고 주장하지 않는다.

**내부 선택 수정과 검증:** [연결 구조 점검과 역반응 질의 수정의 작은 실험](../benchmarks/results/synthesis-route-development-20261023/topology-steering-prototypes-v1.json)을 바탕으로, 반응물 역할 사이의 모든 연결 결합을 끊었을 때 서로 다른 역할의 원자가 같은 연결 성분에 남는지 검사한다. 완전한 비어 있지 않은 대응 열거에서 모두 불가능한 경우에만 내부 규칙을 제외한다. 유지되는 원자 사이의 결합 삭제, 불명확한 매핑, 열거 절단·예산 소진 등은 기존 선택을 유지한다. 추가 작업은 탐색당 대응 요청 128회, 요청당 64개와 절단 감지용 1개, 템플릿·대상 그래프 방문 합계 262,144회다. 규칙 검사 512회 상한은 그대로다.

서로 다른 반응물을 잇는 결합이 정확히 하나임을 확인한 규칙에만, 복사한 역반응 질의의 그 결합에 고리 외부 조건을 추가한다. 고리를 만드는 다중 연결 반응에는 적용하지 않는다. 기존 1회 역반응 호출과 원시 결과 4개 상한을 유지하고 외부·내부 탐색에서 같은 캐시 정책을 쓴다. 실제 정방향 규칙, 원료, 생성물, 경로 감사와 최종 관문은 바꾸지 않는다. 현재 소스의 [계획 점검 및 검토 기록](../benchmarks/results/synthesis-route-development-20261023/topology-production-controls-v1.json)에서 내부 규칙 4개 안에 필요한 결합 규칙이 선택되고, 원시 결과 3개 중 2개가 원자 분할과 실제 역할을 만족하는 고리 사이 질의였다. 특정 규칙 ID를 우선한 결과가 아니다. 관련 테스트 53개 독립 실행 후 발견한 시간 제한 경계 오류를 고쳤고, 최종 소스에서 해당 회귀 테스트 1개와 작성자의 경로 테스트 30개가 통과했다. 전체 저장소 테스트나 실제 합성 검증을 마쳤다는 뜻은 아니다.

**v9 통합 결과와 다음 작업:** [고정된 소스의 12입력 실행](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v9.json)은 38개 입력/생성물 쌍·38개 경로를 3개 입력에서 공급했다. 1단계 16개·2단계 22개, 생성 시간 합계 약 357초다(일회 카탈로그 로딩 제외). 카탈로그·규칙·입력·설정은 v7과 동일하다. 10/12개 입력은 원료 방문 262,144회, 12/12개는 규칙 검사 512회 상한에 도달했다. 7개 입력은 2단계의 신규 원료 역할 검사 전부가 첫 외부 계획에서 발생했다. 선택된 내부 규칙에 필요한 규칙이 포함되었어도 뒤의 중앙 계획은 실제 원료 조회를 하지 못한 구체 사례가 확인됐다.

v10 검증 대상 수정은 외부 계획별 내부 질의 묶음을 준비하고, 역할을 충족한 질의 우선·동률의 기존 순서를 유지한 채 외부 계획을 한 질의씩 순환하는 것이다. 준비 단계의 역반응·정규화 작업과 실제 원료 조회·정방향 실행 비용을 구분해 기록한다. 규칙 선택의 512회 예산을 순환하는 변경은 별도 후속 후보이며 이번 수정과 혼합하지 않는다. 모든 계획에 최악 조건의 완전한 조회를 보장하려면 질의별 첫 조회량을 명시적으로 나누는 정책이 필요할 수 있지만, 이를 이미 해결했다고 표현하지 않는다. [스케줄러 검토 기록](../benchmarks/results/synthesis-route-development-20261023/scheduling-controls-v1.json)의 독립 경로·계량 테스트 55개가 통과했다. 대체 검색 통계 누락에 따른 오류도 회귀 검증으로 수정했다. 소스를 고정해 v10 진단을 수행했다. 이후에도 사전 통과 입력 6개 이상일 때만 모든 단계의 실제 전방 지지·3D 비교로 진행한다. P1 채택 기준은 계속 **전체 경로 지지 입력 >5/12**다.

**v10 통합 결과:** 소스 `cd19b55`에서 12입력 정상 종료·해시 일치를 확인했다. 사전 통과 입력 4개, 입력별 고유 생성물 합 35개, 경로 40개(1단계 16개·2단계 24개)다. 생성 시간 합은 약 377초이며 일회 카탈로그 로딩을 제외한 관측 시간이다. `CHEMBL4247-query-2`의 중앙 계획은 이제 원료 방문 36,448회와 외부 생성 상태 12개를 얻었지만 최종 사전 관문은 통과하지 못했다. 조회 기회를 주는 문제와 적합한 생성물을 찾는 문제를 구분한다. 사전 통과 입력이 4개이므로 실제 모델 비교는 실행하지 않았고 P1은 계속 미완료다.

저장된 탈락 결과에서 `CHEMBL4247-query-2`는 생성물 72개 모두 anchor를 보존했지만 47개가 분자량 제한에서 먼저 탈락했고, `CHEMBL3864-query-1`은 42개 중 28개가 극성 수용량에서 먼저 탈락했다. 반면 `CHEMBL5163-query-2`, `CHEMBL4869-query-1/2`, `CHEMBL3864-query-2`는 anchor 통과 생성물이 0개였다. 이들은 관측된 첫 탈락 이유이며, 다른 관문을 통과했다거나 해당 입력의 합성이 불가능하다는 결론이 아니다. 다음 설계는 이 서로 다른 실패를 하나의 유사도 가중치 조정으로 처리하지 않고, 구체 경로에서 입체 정보의 출처와 후보 선택 손실을 먼저 확인한다.

[미충족 입력과 입체 정보 출처의 후속 진단](../benchmarks/results/synthesis-route-development-20261023/v10-uncovered-inputs-v1.json)은 저장 결과를 재사용했다. `CHEMBL5163-query-1`의 가까운 탈락 사례는 고정 카탈로그를 한 번 텍스트로 읽어 원료 ID 2개만 조회했다. 첫 원료에 이미 미지정 황 입체중심이 있고, 두 번째 원료에는 지정된 탄소 입체중심이 있었다. 생성물에도 이 두 종류가 관찰되지만 저장된 탈락 경로에는 원자별 대응이 없어 해당 황의 이동을 정식 감사로 입증한 것은 아니다. 카탈로그의 미지정 입체 정보를 생성 과정에서 해결된 것으로 취급해서는 안 된다.

다음 작은 검증은 **반응 후에도 남는 미지정 원료 입체중심을 원자 출처로 확인하는 양성·음성 대조**다. 필요한 경우 원료 선택 전에 이 조건을 적용하되, 반응에서 사라지는 중심까지 일괄 제외하거나 임의로 입체 배치를 정하지 않는다. 동시에 규칙 선택에서 준비되지 않은 계획과 실제 조회 예산을 받지 못한 계획을 별도로 집계해 첫 조회량 배분의 효과를 검토한다. 개선 가설 하나마다 제한된 대조·검토를 먼저 끝내고, 새로운 소스에서 12입력을 다시 실행할 때에는 변경 요인과 예산을 명시한다. 원료·규칙 자산 확장, 더 깊은 다단계, 조건·문헌 추가는 이 고정 자산 P1 비교와 별도 단계로 관리한다.

**입체 정보 사전 선별의 근거와 수정 범위:** [작은 실제 규칙 재생과 저장 질의 점검](../benchmarks/results/synthesis-route-development-20261023/conserved-stereo-and-anchor-controls-v1.json)에서 위 황 중심이 실제 규칙 `039` 재생의 정확한 생성물에서도 같은 원료 원자에서 유래한 미지정 중심으로 남음을 확인했다. 별도의 원자 추적 대조에서는 미지정 중심이 반응에서 사라질 수 있음을 확인했다. 처음에는 제품에서 중심이 반드시 남는 경우만 증명해 제외하는 방안을 검토했다.

그러나 실제 `audit_route`의 기존 `strict_eligible` 조건은 **모든 단계의 모든 반응물에 `stereo_state(...)["fully_specified"]`를 요구**한다. 따라서 중심이 제품에서 사라지는 경우에도 미지정 원료는 현재 정책에서 승인되지 않는다. 화학적으로 해당 반응이 불가능하다는 뜻은 아니다. [전체 경로 감사 대조](../benchmarks/results/synthesis-route-development-20261023/strict-reactant-stereo-controls-v1.json)에서 같은 생성물 `CN`을 만드는 미지정 원료는 strict 감사에 탈락하고 지정 원료는 통과함을 확인했다. 이 필요조건을 그대로 원료 선택 앞으로 옮기는 것이 더 직접적인 수정이다. 원료를 순위에서 선택할 때 같은 입체 검사로 탈락이 확정된 원료를 건너뛰고, 이미 방문한 같은 풀에서 다음 원료로 top-k를 채운다. 내부·최종 단계에 같은 기존 조건을 적용하며, 중심 보존 증명이나 추가 역할 매칭·반응 재생은 하지 않는다. 실패·예산·시간 제한으로 판정하지 못한 후보는 기존 선택을 유지하고 불완전 조회를 완전한 결과로 캐시하지 않는다. 추가 검사 횟수·크기 작업량·캐시·예시 기록은 명시적으로 제한한다. [사전 선별 코드 검토](../benchmarks/results/synthesis-route-development-20261023/source-stereo-review-v1.json)와 독립 테스트 57개가 통과했으며 v11 고정 소스 진단에서는 원료 입체 실패를 줄였으나 사전 통과 입력 확대는 없었다. 다음 단계는 알려진 성공 원료의 실제 검색 풀·순위를 확인하는 것이다.

**원료 풀 누락 위치 확인:** [알려진 성공 경로 원료의 조회 관찰](../benchmarks/results/synthesis-route-development-20261023/known-witness-retrieval-v1.json)에서 `CHEMBL4247-query-2` 한 입력을 v11과 같은 조건으로 다시 실행했다. 저장된 성공 경로의 원료는 조회가 끝난 뒤 비교만 했고 검색에 주입하지 않았다. 소요 시간을 제외한 생성물·관문·작업 계량 필드가 v11과 모두 일치했다. 해당 규칙·역할의 실제 조회에서 두 성공 경로의 원료 합집합 4개는 모두 8,192개 bucket 풀과 입체 anchor 목록에 없었다. 따라서 이 원료들의 첫 누락은 top-k 순위 이전의 풀 구성 단계다. 다른 원료로 경로를 찾을 수 없다는 뜻은 아니다.

**반응 부위 주변 크기 특징만 바꾸는 대안은 미채택:** [metadata 시제품 v1](../benchmarks/results/synthesis-route-development-20261023/reaction-local-pool-prototype-v1.json)은 카탈로그 238,542개 구조·920개 bucket을 한 번 읽어 기존 풀 소속 160건을 오차 없이 재현했다. 관련 원료/질의 20건 중 18건은 원료 bucket까지 조회하지 못했고, 2건은 같은 bucket의 해시 순서가 8,192개 상한 밖이었다. 국소 특징으로 알려진 원료 4개 중 aryl-Br 원료 하나만 관련 풀에 들어왔으며 완전한 경로의 원료 조합은 복구되지 않았다. 명시적 N 원자 하나와 재귀 방향족 조건으로 표현된 역할은 match 원자에 부착 고리가 포함되지 않아 국소 특징이 오히려 나빠졌다. 이 결과는 후보 생성·경로 재생·전방 예측을 수행한 결과가 아니다.

**역할 색인 네 조건 비교도 미채택:** [metadata 시제품 v2](../benchmarks/results/synthesis-route-development-20261023/reaction-role-pool-prototype-v2.json)는 기존/국소 특징 × 정확한 역할 색인 유무를 비교했다. 국소 특징 v2는 모든 역할에 동일하게 match 원자와 바로 인접한 원자를 고리 확장의 시작점으로 사용했다. 역할 색인은 외부 계획 8개의 역할 발생 16건에서 빈도 상위 2개를 선택하고 동률은 정규화 SMARTS 사전순으로 실행 전에 고정했다. 두 역할은 각각 원료 44,191개·68,643개에 대응했으며 추가 검사는 477,084회였다. N 역할은 지방족 아민과 방향족 NH2 대안을 모두 포함하므로 aniline 전용 색인으로 해석하지 않는다. 기존 풀 소속 160건·v1 순위 304건을 모두 재현했다. 필요한 내부 규칙 036의 17회 조회(고유 질의/역할 11개)에는 선택한 정확한 역할 색인이 적용되지 않았다. 네 조건 모두 필요한 원료 조합을 풀에 모으지 못했고, 국소 특징을 쓴 조건에서만 공유 aryl-Br 원료 하나가 도달했다. 추가 작업에도 완전한 경로 회복 근거가 없어 production에 적용하지 않는다.

**다른 역할의 색인 재사용만으로는 충분하지 않다:** 같은 guide 부위에 대응하는 다른 역할의 색인을 검색 힌트로 쓰는 대안도 검토했다. 그러나 누락된 aniline 원료는 이미 정확히 같은 N 역할 색인을 적용한 모든 관련 조회에서 풀 밖이다. 정확한 역할을 우선하고 나머지에만 다른 색인을 쓰는 정책으로는 이 원료의 결과가 바뀌지 않아, 알려진 두 경로의 완전한 원료 조합을 복구할 수 없다. 이를 확인하기 위해 카탈로그를 다시 읽거나 production을 수정하지 않았다. 다른 원료를 사용하는 모든 경로의 가능성에 대한 결론은 아니다.

다음 수정안은 **역할 내 풀 구성과 질의 크기 표현**에 집중한다. 가장 가까운 큰 bucket의 해시 앞부분만 선택하는 편중과, 전체 질의에서 너무 큰 원료를/국소 질의에서 너무 작은 원료를 우선하는 문제를 분리해 평가한다. 먼저 저장된 bucket 통계로 고정 정책을 비교하고, 새 도달성뿐 아니라 기존 도달성 손실도 기록한다. 이후 실제 top-k·경로 생성·감사·원 입력 관문을 확인하며, 사전 통과 입력이 6개 이상이어야 동결한 모델·3D 비교로 진행한다. 단계마다 원료 구조와 ID, 규칙, 정확한 중간체, 최종 생성물과 실패/미평가 이유를 보존한다.

국소 특징은 실제 분자가 아닌 조회용 벡터다. 불명확·잘린 역할 대응은 기존 특징으로 복귀하며, 저장된 성공 구조는 결과 비교에만 사용한다. 역할 색인과 국소 특징 모두 아직 production에 적용하지 않았다.

**중간 크기 표현의 구현 근거:** [metadata 시제품 v3](../benchmarks/results/synthesis-route-development-20261023/reaction-pool-scale-prototype-v3.json)는 카탈로그를 다시 읽지 않고 저장된 histogram을 사용했다. 전체/국소 원시 특징 수의 산술평균을 올림한 뒤 기존 bin을 적용하는 식을 먼저 고정하고, 세 특징 표현 × 세 색인 정책의 9조건을 비교했다. 기존 순위 1,216건·실제 풀 소속 160건을 재현했다. 중간값과 정확한 역할 우선/같은 부위 색인 재사용을 결합한 조건에서만 알려진 `route_000006`의 aryl-Br·heteroaryl-I·aniline 원료가 필요한 역할의 풀 순번 6,421·3,369·6,208에 들어왔다. 첫/세 번째 원료 조회는 기존 실행의 2단계 호출에서 캐시 재사용된 기록도 있다. 다른 알려진 경로의 heteroaryl-Br는 여전히 제외됐다.

이 결과는 **필요 원료 도달성의 상한**이며, 실제 top-k 선택·같은 작업 항목의 결합·정방향 생성·전체 감사의 성공이 아니다. 저장된 76개 질의/역할 × 4개 원료의 가상 풀 비교에서는 기존 대비 새 도달 6건·손실 2건이었다. 이 분모에는 역할에 맞지 않는 원료와 기존 예산 소진 호출도 포함되므로 일반적인 후보 품질 지표로 해석하지 않는다. 새 metadata 작업은 window match 76회, site match 207회, 합계 graph 방문 12,120회였다. 같은 부위는 완전한 대응 목록의 **동일한 원자 집합**을 뜻하며, 일부 원자 겹침이나 서로 다른 역할의 후보집합 포함관계를 뜻하지 않는다. 이제 이 고정 정책을 제한된 실제 검색에 구현하고, 테스트·독립 검토 후 소스를 고정해 통합 경로 공급을 확인한다.

## 출발점과 해석 범위

[추적되는 고정 12입력 경로 기준선](../benchmarks/results/synthesis-route-development-20261023/baseline.json)은 공개 개발 입력 12개(6표적)의 재사용 결과다. 12개 모두 실행을 완료했지만 qualified 결과는 0개였다. 저장된 기록에는 경로 683건, 계산적으로 지지된 경로 기록 304건(12입력 중 5개), 입력별로 중복 제거한 지지 생성물 69쌍이 있다. 이 수치는 동일 구조의 반복 경로를 포함하는 기록 수와 고유 생성물을 혼동해서는 안 된다. 각 생성물의 **첫 번째** 지지 경로만 보면 67개는 1단계, 2개는 2단계이며, 그 첫 경로의 정확한 최종 생성물은 해당 모델이 적어 낸 목표 생성물과 일치하지 않았다. 대체 경로 전체에 대한 결론은 아니다. 상세 실행 계획과 원본 경로·분석 자료는 Git에서 제외된 로컬 `benchmark-results/qualified-development-20261023/`에 있으며, 위 기준선에 파일 SHA-256을 고정했다.

저장된 3D 점수 계산 시도/기록은 39건(전역 고유 생성물 수라는 뜻은 아님)이고 screening 통과는 0개였다. 설계 41건은 지정되지 않은 입체화학 때문에 제외됐다. 전방 예측 호출 예산 소진으로 평가하지 못한 경로 기록 194건은 화학적 실패로 세지 않는다. 입력 대 최종 생성물의 비교에는 같은 지문 정의를 써야 한다. native 설계 표의 유사도(sparse Morgan **count**, radius 2)와 최종 qualification의 bit 지문 유사도를 직접 연결한 감소율은 계산하지 않는다. 이 기준선은 저장된 생산자 기록의 기술 통계이며 독립적인 합성 검증, 생물학적 효능 또는 홀드아웃 성능이 아니다.

## 구현 순서

| 순서 | 작업과 코드 접점 | 완료 조건과 선행 관계 |
|---|---|---|
| P0: 경로 단위 기준선 | `chembounce_synthesis/workflow.py`, `routes.py`, `evidence_outcomes.py`의 기존 저장 필드를 사용해 각 입력→정확한 생성물→경로 ID→단계별 검증/전방 결과→예산 상태를 구분해 보고한다. 심사 가능한 후보 목록은 `results.json`의 qualified 반환과 별도 파일/표기로 둔다. | 0/미평가/실패를 분리하고 경로·생성물 중복을 제거할 수 있어야 한다. 저장된 raw proposal, 카탈로그·규칙 해시, 결정 이유를 추적할 수 있어야 한다. 이 단계의 진단 목록은 사용자에게 qualified 추천으로 표시하지 않는다. |
| P1: 실제 경로에서 후보 만들기 | `reactions.py`의 실제 반응 규칙과 `catalog.py`의 구체적 building block을 입력으로, `routes.py`에 **한 단계 우선, 최대 두 단계까지** 제한된 경로 유도 탐색을 추가한다. 기존 반응성 호환성/가까운 building block 색인으로 조합 전 후보를 줄이고 명시적 beam·조합·단계·시간 상한을 적용한다. 전체 분자 생성물을 규칙으로 재생한 뒤 원 입력의 지정된 주변 anchor/특징과 보존되는 원자의 mapped stereo를 확인한다. 치환으로 CIP R/S 표기가 달라질 수 있으므로 문자열의 R/S만 비교하지 않으며 새 불명확 입체중심은 임의로 정하지 않고 제외한다. 원래 scaffold 전체를 고정하지 않는다. 완전한 구체 경로를 얻으면 `workflow.py`의 intake에 넘겨 중복 LLM 제안을 하지 않는다. 모델의 목표 구조 문자열은 검증된 생성물을 대신하지 못한다. | P0 및 알려진 양성/음성 반응 fixture가 선행한다. 동일 catalog/rule snapshot에서 생성한 경로가 `verify_route`, 전체 atom/stereo audit, 정확한 생성물 일치와 기존 설계/최종 제품 관문을 통과해야 한다. 전역 catalog×rule 열거는 하지 않는다. 새 생성 정책은 명시적 opt-in 프로필/설정과 source binding을 갖고 v7 기본값을 조용히 바꾸지 않는다. 이 작업이 가장 가까운 실제 화학 개선이다. |
| P2: 다단계 연결과 근거 예산 | `routes.py`의 DAG 재생/확장(`expand_route`)과 `workflow.py`의 기존 경로 검색·전방 예측 캐시와 이유별 구분을 활용해, 앞 단계 생성물에 의존하는 다음 단계의 frontier를 관리한다. 현재의 생성물/설계별 첫 경로 배분을 보존하며, v6의 별도 family/design 순환 배분은 기본값으로 취급하지 않는다. 반복 호출 합치기는 준비된 반응물·시약과 예측기 출처까지 포함하는 기존 안전한 cache key에 한정하고, 경로/맥락별 audit는 따로 유지한다. 미평가 경로와 이미 지지된 경로 사이의 예산 배분을 명시한다. | P1의 1–2단계 경로가 먼저 정확히 재생돼야 한다. 연결되지 않은 단계, 중간체가 다른 경로, 순환, 예산 중단을 음성/미평가 fixture로 분리한다. 예산 배분 변경은 새 프로필/명시적 설정과 출처로 기록하고 v7 기본 정책을 조용히 바꾸지 않는다. |
| P3: 실험 맥락 | 기존 `reaction_records.py`의 공개 ORD 기록 처리와 `catalog.py`/`route_audit.py`의 leaf 출처를 재사용해, 확인 가능한 반응 조건, 공급사 SKU·재고 시점, 보호기/선택성 등의 근거를 별도 필드로 연결한다. | 출처 URL/식별자·조회일·구조/반응 대응이 없는 항목은 `unknown`이다. 현재 카탈로그 등재와 계산 예측을 구매 가능성, 수율 또는 실험 합성 가능성으로 승격하지 않는다. 외부 자료가 확보되기 전에는 이 단계가 P1/P2의 계산 경로 관문을 대체하지 않는다. |

P1은 기존 모델이 그럴듯한 반응 문장을 내길 기다리는 대신, 실제 카탈로그 잎과 규칙 적용으로 **재생 가능한 최종 구조**를 먼저 만든다. 그 뒤 원래 hit의 필요한 약리 특징/anchor와 명시된 stereo를 유지할 수 있는지만 판단한다. 넓은 무제한 열거는 하지 않는다. 전방 예측은 각 단계의 제한된 계산 근거이고, `catalog_and_rule_verified`는 규칙/카탈로그 일치일 뿐 실험 성공이 아니다. P2에서 다단계를 늘려도 모든 의존 단계가 확인돼야만 전체 경로를 지지된 것으로 부른다.

## 제안하는 검증 게이트 (관측 성과 목표가 아님)

1. **작은 화학 fixture 먼저:** 카탈로그와 규칙으로 직접 만든 알려진 양성 1단계·2단계 경로, 결합 위치가 다른 음성, 누락 중간체, 잘못된 생성물, 불명확/반전된 입체화학, 서로 다른 catalog ID·중복 경로를 포함한다. `verify_route`와 전체 경로 audit의 결과, 저장/재생 결과가 일치해야 한다. 임의의 SMILES 수선, 부분 경로 승인, 실패 후 조용한 재시도는 허용하지 않는다.
2. **동일 비용의 쌍 비교:** fixture 통과 후에만 같은 12개 개발 입력, native/provider seed 42와 최종 refinement 42/43/44, 고정 asset/hash, 입력당 960초, 동일 GPU 기종·스레드 한도 및 현재 3D/qualification 임계값으로 기존 v7과 새 명시적 설정을 나란히 실행한다. 실행 전 후보·분기·경로·모델 호출·토큰·생성물 상한과 GPU/CPU 배치, 자산 로딩을 포함한 시간/자원 청구 방식을 함께 동결한다. 모델·규칙·카탈로그 변경이 있으면 별도 요인으로 기록한다. 한 입력의 시간초과/오류는 0개로 대입하지 않는다. 변경 후 새 12회 실행은 새 폴더에 보존한다.
3. **계량 단위:** 입력별 검증 경로 보유율, 지지된 **고유 정확 생성물** 수, 모든 단계가 audit·전방 예측을 마친 전체 경로 수, 1/2/다단계 분포, 예산 미평가율과 단계별 이유, proposal→검증 경로→3D screening→refinement→qualified 반환의 각 분모를 함께 보고한다. 입력과 재생 최종 생성물의 유사도/보존 특성은 동일 지문·동일 구조 정의로 다시 계산한다. 중복 경로 수 증가는 성공 지표가 아니다.
4. **채택 조건:** 알려진 양성 경로가 재생되고 음성·stereo fixture는 거절될 것, 기존 최종 관문이 약해지지 않을 것. 첫 실행 전에 고정한 주 지표는 **정확한 변경 scaffold 생성물의 전체 경로 audit·단계별 전방 지지를 모두 갖춘 입력 수**다. 고정 총 상한 안에서 기준선 5/12개보다 증가해야 경로 개선으로 채택한다. 완전히 감사된 고유 입력/정확 생성물 쌍 수는 보조 지표이며, 결과를 본 뒤 주 지표와 바꾸지 않는다. 다른 지표의 감소, 미평가·실패·비용 증가는 함께 보고한다. 최종 qualified 수는 별도 결과로 남긴다. 3D에서 다시 탈락하면 경로 개선을 qualified 성공으로 부르지 않는다. 개발 패널의 개선은 후속 독립 입력 검증 전까지 일반화하지 않는다.

현재 P1 구현안은 명시적 `route_first` 설정에서 실제 catalog+rule 후보를 1단계 우선·최대 2단계까지 생성하고, 완전한 경로를 기존 intake와 전방 근거·3D·qualification 단계로 넘긴다. 후보와 최종 추천은 별도 파일에 기록한다. 국소 입체 anchor의 대응이 불명확하거나 바뀌면 보수적으로 제외하며, 전역 원자 대응을 추정하지 않는다. 이 구현안의 채택 여부는 위 고정 예산 비교와 원래 관문의 유지 여부를 검토한 뒤 결정한다. P2의 일반 다단계 frontier/예산 정책은 별도 변경이다.

**중간 크기 검색 구현 검토:** [독립 검토 기록](../benchmarks/results/synthesis-route-development-20261023/midpoint-retrieval-review-v1.json)에서 최종 소스의 경로·telemetry 테스트 63개와 저장된 질의 76개의 특징/색인 선택 일치를 확인했다. 불완전한 부위 metadata가 중간값을 계속 사용하던 문제, target을 빠뜨린 metadata 캐시 키, 크기 제한 전 추가 count 계산을 수정했다. 역할 색인만 미완성이면 해당 부분집합을 폐기하고, metadata 자체가 불완전하면 전체 기존 특징·색인 선택으로 복귀한다. 구조 작업량은 명시적 크기 기반 계량이며 모든 Python 연산 수나 동일 CPU 비용을 뜻하지 않는다. 다음 v12 실행은 같은 12입력·관문·기존 검색 상한을 유지하며 추가 역할 색인·metadata 비용을 별도로 보존한다.

**후보 평가 예산 수정 검토:** [독립 검토](../benchmarks/results/synthesis-route-development-20261023/admission-reserve-review-v1.json)에서 최종 소스의 경로·telemetry 테스트 66개가 통과했다. 예약량은 검색이 쓸 수 없는 최소 평가 몫이며, 실제 평가에는 쓰지 않은 검색 몫까지 포함한 남은 전체 예산을 허용한다. 1단계 전용 검색은 2단계용 절반 상한을 적용하지 않는다. 초기 hit·생성·입장 순위·callback의 실제 지문 과금을 따로 기록하고 합계를 검사한다. 순위를 못 계산한 후보와 순위는 계산했지만 callback을 시도하지 못한 후보도 구분한다. v13 실행기는 기존 입력·관문·상한을 유지하고 모든 제한된 대기 경로 그래프를 미검증 상태로 별도 저장한다.
