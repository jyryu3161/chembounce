# 합성 경로 우선 개발 계획 (2026-10-24)

목표는 **입력의 필요한 구조·입체·약리 특징을 보존하면서 scaffold가 달라지고, 구체 원료부터 정확한 최종 생성물까지 검토 가능한 합성 경로를 가진 후보**를 제안하는 것이다. 계산 방법론 논문을 우선하며 합성·활성 실험 협업은 미정이다. 계산 경로 검증, 실제 합성 성공, 활성 보존을 각각 구분한다.

**P1은 미완료다.** 최근 전체 모델·3D 비교에서 모든 단계가 계산적으로 지지된 입력은 **4/12개**, 기준선은 **5/12개**, 채택 기준은 **최소 6/12개**다. 실험 코드는 `feat/route-first-generation`에 유지한다. 현재 기본 추천 프로필은 `qualified-selective-engineering-v7`이며 실험 선택 옵션은 기본 비활성이다. P1 채택 전에는 해당 기능을 `develop`에 병합하지 않는다.

최신 v22의 전체 12입력 대조는 기존 후보 집합을 그대로 보존했으며 새 통과 경로는 없었다. 이후 **반응 부위 표시를 이용한 원료 선택의 한 입력 대조**에서 관문 통과 생성물은 4→5개, 정확 경로는 6→8개로 바뀌었다. 새 경로 3개와 손실 경로 1개를 함께 기록했다. 추가 3경로를 고정해 평가한 결과 **2경로는 두 단계 모두 정확한 전방 예측 지지를 받았고, 1경로는 첫 단계가 불일치했다.** 3D·최종 적격 판정과 전체 입력 비교는 아직이며, 전체 P1 성적은 바뀌지 않았다.

**이번 업데이트의 우선순위는 경로의 검토 가능성 → 단계별 조건·선택성 근거 → 새로운 지지 경로 확보 → 독립 검증이다.** 추천이 없는 실행에서도 어느 반응 단계가 막혔는지 확인하는 첫 구현은 완료했다. 다음 기능 작업은 단계별 조건·선택성 근거 연결이다. 보고 기능의 완료와 기존 P1 성능 달성은 별도다. 경로 길이 증가, 합성 용이성 점수 하나로 판정하기, 출처 없는 조건·수율 추정은 선행 작업으로 두지 않는다.

현재 계획은 이 문서가 기준이다. 과거의 상세 실험·수정·비채택 판단은 [개발 이력](SYNTHESIS_ROUTE_HISTORY.md)에 원문과 해시를 보존했다.

## 실행 순서와 완료 기준

P1의 성능 목표를 유지하면서, **단계별 검토 기능과 합성 근거 보강을 함께 진행한다.** 경로 수·깊이를 늘리는 일보다 실패한 단계와 근거 누락을 확인하는 일이 먼저다.

| 순서 | 작업·코드 접점 | 구체 산출물·완료 조건 |
|---|---|---|
| 1. 실패 단계까지 보이는 경로 검토 — 완료 | `report.py`, 새 `report_routes.py`, `tests/synthesis/test_report_unselected.py`. 저장 경로의 결합 검증과 통과 여부 검증을 분리했다. | 추천 0개여도 **저장된 미선택 경로 최대 16개**를 저장 순서로 표시한다. 전체/표시/생략 수, 원료→중간체→최종 구조, 기대/예측 생성물, 실패 단계, 조건 누락, 원료 출처를 제공한다. 관련 검사 408개·독립 검토·실제 저장 12실행의 HTML 생성을 통과했다. 빠진 단계와 손상된 근거는 미확인으로 남긴다. |
| 2. 단계별 조건·선택성 근거 — 1번의 자료 구조 사용 | `evidence.py`, `computational_support.py`, `reaction_records.py`, `catalog.py`, `report.py`. 기존 정확 반응/조건 대응을 재사용한다. | 아래 근거 규약에 따라 조건별 제공/누락/출처/모델 사용 여부를 기록하고, 다른 반응 부위·입체·조건의 자료가 전용되지 않음을 검사한다. 다중 반응 부위와 선택성 미확인을 명시한다. 조건이 없을 때도 누락을 설명하는 기능은 완료할 수 있으나 해당 경로의 합성 근거 확보로 세지 않는다. |
| 3. 새 지지 경로를 공급할 선택 개선 — 구현·저장소 검사 완료, 12입력 대조 중 | `route_first.prefer_marked_continuation_second`를 기본 OFF로 구현했다. `prefer_continuation_second=true`가 필요하며 사전 고정한 정책·후보 폭·공통 작업 상한을 유지한다. | 추가 3경로 중 **2경로의 두 단계 모두 지지**를 확보했다. 집중 검사 109개·독립 코드 검토·전체 저장소 검사를 통과했다. 고정 12입력 생성 대조에서 기존 지지 경로·최종 적격 3경로·N–H 양성과 새 지지 경로의 보존 및 실제 선택 순서를 확인한다. 손실·미평가·전체 작업량도 보고한다. |
| 4. P1 전체 경로 대조·채택 — 3번의 새 후보가 전제 | 동일 자산·예산에서 실제 전방 모델과 3D/qualification을 평가한다. | 새 후보 집합에 전체 지지 입력이 5개를 넘을 근거가 있고 관련 테스트·독립 검토·전체 저장소 검증을 통과했을 때 실행한다. 실제 전체 경로 지지 **최소 6/12개**가 P1 기준이며 qualified·손실·미평가·비용도 보고한다. |
| 5. 대체 경로 비교·독립 검증 — 검증 설계 선행, 실행은 P1 이후 | `routes.py`, `workflow.py`, 보고 기능을 확장한다. 별도 패널의 선정·중복 검사·지표는 결과를 보기 전에 고정한다. | 동일 최종 생성물의 대체 경로마다 단계별 지지·조건 근거·원료 출처·단계 수를 나란히 비교한다. 검증된 비용/수율이 없으면 순위에 넣지 않는다. 안정된 구현을 별도 입력 패널과 같은 예산의 기준선·구성요소 제거 대조로 평가한다. 3단계 이상·새 자산·새 예산은 별도 실험이다. |

1–2번은 P1 성공률을 올렸다고 주장하지 않는 독립 작업이다. 기존 donor 진단은 [종료·복구 기록](../benchmarks/results/synthesis-route-development-20261023/donor-feature-diagnostic-v1.json)을 보존하고 후속 원료 검색으로 연장하지 않는다. 구현은 **GPT-6-Sol medium**, 독립 검토는 **Astra**로 진행한다. 작업마다 변경 파일·검증·남은 한계를 별도 보고하며, 불확실한 실험 결과를 날짜로 약속하지 않는다.

## 경로 검토 화면의 최소 규약

각 경로에서 **입력 → 최종 구조 → 원료 → 정확한 중간체 → 단계별 생성물**을 추적한다. 다음 상태를 한 점수로 합치지 않는다.

| 표시 항목 | 판정 규약 |
|---|---|
| 입력과의 관계 | 원 입력 기준 2D 유사도, 3D 형태·약리 특징, 지정 입체 보존, 실제 scaffold 변경 범위를 별도로 표시한다. |
| 경로 결합 | 그래프 node ID, 순서 있는 반응물, 정확한 생성물·규칙 ID·경로 바인딩으로 재생/감사/전방 기록을 연결한다. 다른 위치·입체이성질체의 근거를 옮기지 않는다. |
| 단계별 계산 근거 | 규칙 재생, 원자/입체 감사, 전방 예측의 완료·유효·일치 상태를 나누고 기대/예측 구조를 보여준다. 한 단계라도 미평가이면 전체 지지로 표시하지 않는다. |
| 반응 맥락 | 조건 제공 여부와 모델 사용 여부를 구분한다. 현재 ReactionT5 어댑터는 반응물·시약을 사용하며 온도·시간은 사용하지 않는다. ORD 연결은 보고용이며 자동 승인 근거가 아니다. |
| 원료·문헌 근거 | ID/구조/출처, SKU·조회일·재고 확인 여부, 정확 반응/유사 반응 여부를 표시한다. 출처가 없거나 대응이 모호한 조건·수율은 미확인이다. |
| 실패·누락 | 불일치, 예산 미평가, 자료 누락/손상, 실행 오류를 구별한다. 계산 불일치를 실험 합성 실패로 표시하지 않는다. `qualified`는 현재 계산 관문 통과 상태다. |

`_route_steps`는 선택된 적격 경로를 전제로 하므로 거절 경로에 그대로 적용하지 않는다. 그래프/근거 결합 검증과 적격성 판정을 분리해, 거절 근거도 표시하되 누락·모순을 확인된 경로로 승격하지 않는다. 선택 주 경로와 중복 표시하지 않고 추천 목록·최종 판정은 유지한다.

**완료 검증:** 추천 0개/거절 2단계, 부분·누락·손상된 예측, 잘못된 node/반응물/생성물 결합, 선택 경로 중복, HTML escaping, 표시 상한/생략 수, 기존 선택 후보 보고 회귀를 확인한다. 이 기능의 실행은 저장 자료만 사용하며 반응 생성·모델·3D를 호출하지 않아야 한다.

**구현·검증 결과:** 보고/전방 근거 관련 검사 **408개**, Ruff와 Astra 독립 검토를 통과했다. [실제 저장 12실행의 보고 생성](../benchmarks/results/synthesis-route-development-20261023/unselected-route-report-control-v1.json)에서 기존 선택 후보와 선택 자료 일관성은 이전 코드와 같았다. 미선택 13경로·21단계는 기록상 전체 일치 6경로, 불일치 포함 6경로, 미완료/미확인 1경로로 표시됐다. 이는 기존 기록의 표시 분류이며 새 경로 평가가 아니다. RDKit·Torch를 로드하지 않았고 화학·모델·3D 호출은 0회다. HTML과 CLI는 기존 선택 자료와 **표시된** 미선택 자료의 일관성을 각각 표시하며, 어느 검토 범위든 불일치이면 CLI 종료 코드는 3이다. 하나의 단계 기록이 빠지거나 손상돼도 독립적으로 결합이 확인된 다른 단계의 상세 자료는 유지한다. 현재 P1의 실제 4/12개 성적은 바뀌지 않았다.

## 조건·선택성 근거의 구현 규약

경로별로 **규칙 재생 / 원자·입체 감사 / 단계별 전방 지지 / 반응 관찰 근거 / 원료 조달 근거**를 별도 항목으로 제공한다. 경로 수준의 전방 지지는 모든 단계가 완료·일치할 때만 성립한다. 모델 순위나 합성 용이성 점수를 실험 성공 확률로 바꾸지 않는다.

- **조건 항목:** 시약·촉매·용매·온도·시간·당량·보호/탈보호·후처리·분리·수율을 출처가 있는 범위에서 표시한다. 값이 없는 항목과 원문에서 해당 없음이 확인된 항목을 구분한다. 기존 `context_complete`/`supplied_unvalidated`와 별도로 검토용 누락 목록을 만들며 기존 추천 관문은 변경하지 않는다.
- **정확한 대응:** 기존 정확 구조·반응물 개수·조건 대응을 유지한다. 동일 생성물 문헌만 발견한 경우에는 그 경로의 관찰로 올리지 않는다. 유사 반응 참고는 별도 자료 유형이며 현재 ORD 정확 대응으로 자동 생성할 수 있다고 가정하지 않는다. 수율은 관찰된 특정 반응의 값이고 새 경로의 예상 수율이 아니다.
- **선택성:** 동일 역할의 여러 반응 부위, 위치·화학·입체 선택성, 보호기 필요성의 근거와 미확인을 표시한다. 다중 부위 존재만으로 반응 실패를 판정하지 않는다. 원자 대응과 경쟁 생성물 근거가 확보된 경우에만 특정 실패 원인을 부여한다.
- **원료 조달:** 구조와 공급자 ID/SKU 대응, 조회일, 재고 확인 출처를 연결한다. 현재 catalog의 SKU·재고 검증은 미확인 상태이므로, 출처 연결만 완료한 경우에는 카탈로그 등재로 표시한다. 입체·염 형태가 다른 상품을 동일 원료로 취급하지 않는다.
- **모델과 자료의 경계:** 현재 ReactionT5는 온도·시간을 사용하지 않는다. 조건을 표시하는 개선과 조건을 사용하는 예측기 도입은 별도 작업이다. 새 예측기·새 반응 규칙·문헌 자산 확장은 버전과 기준선을 새로 고정한다.
- **완료 검사:** 정확 대응, 다른 위치/입체이성질체, 다른 조건, 부분 조건, 서로 충돌하는 관찰, 원문 누락, 카탈로그 등재만 있고 재고 확인은 없는 경우를 검사한다. 근거 부족 시 상태가 승격되지 않아야 한다.

## P1의 다음 변경을 결정하는 기준

**한 입력에서 새 전방 지지 경로 2개 확보 — 반응 부위를 표시한 원료 비교:** guide와 원료 각각에서 증명된 이탈 부위를 동일한 부착 표시로 치환한 표현을 비교한다. 실제 반응 규칙의 원자 대응으로 치환 가능한 부위를 확인하고, guide는 tagged reverse 출처로 임시 이탈기의 기원을 추가로 증명해야 한다. 다른 치환기·입체·전하를 보존한다. 여러 부위가 있으면 완전하게 열거한 안전한 표현 전부를 평가하고 하나라도 불완전하면 미확인으로 처리한다. 가장 큰 유사도는 가능한 한 부위의 구조 점수일 뿐 실제 반응 부위·선택성·합성 가능성의 근거가 아니다. 부위가 많은 원료에 유리한 편향도 별도 검증 대상이다.

현재 [고정 대조 기록](../benchmarks/results/synthesis-route-development-20261023/departing-site-marker-set-control-v1.json)의 상태는 **`complete_synthetic_only`**다. 사전 검토 후 한 번 실행했고 종료 코드 0, 실행 전후 바인딩 일치를 확인했다. 실제 규칙의 역반응 1회에서 raw 결과 1개를 얻었고 Cl/Br 표현 둘 다 부모 유래 spectator Cl을 보존한 동일 표시 구조를 만들었다. 예제 원료의 두 부위·두 표현을 모두 평가한 최대 점수는 0.25다. 지문 3회, 전체 역할 매칭 5회, 명시 파싱 2회와 내부 파싱 예약 2회, 유사도 2회를 사용했다. 카탈로그 순위·전방 생성·모델·3D는 실행하지 않았다. 개발 결과를 보고 세운 가설임을 유지하며 다음 단계만 순서대로 판단한다.

1. **완료:** 고정 예제의 실제 tagged reverse 대조와 대표 이탈기 변화·spectator 보존을 확인했다. 별도 단위 검사 5개는 다중 부위, 입체·전하·동위원소, 열거 중단·예산 소진과 불완전한 부위 집합의 배제를 다뤘다. 이 검증은 검색 정책 채택 기준이 아니다.
2. **완료:** 실제 guide 출처·조회 문맥별 캐시·모든 부위 평가 비용·미확인 시 기존 선택 유지 규약을 갖춘 별도 정책을 사전 고정했다. 기존 두 번째 원료와 일반 순위의 앞선 대안 15개를 고정한 뒤 모두 평가하며, 첫 원료·anchor·반응 전 top-2를 유지한다. 완결된 목록을 확보하지 못하거나 부위·예산이 불확실하면 기존 선택을 그대로 유지한다. 특정 성공 원료 ID를 주입하거나 생성물 결과로 후보 목록을 보충하지 않는다. 추가 지문·역할 매칭은 기존 공통 상한에 포함한다.
3. **한 입력 생성·전방 대조 완료:** `CHEMBL4247-query-2`에서 4→5생성물, 6→8경로가 됐다. 추가 3경로에는 기존 생성물에 대한 새 경로 1개도 포함된다. 이 3경로를 모두 고정해 감사·평가했고, 2경로가 모든 단계 지지를 받았다. 같은 정책을 기본 OFF로 구현하고 고정 12입력 생성 대조에서 원 입력 유사도·극성·입체·scaffold 관문, 기존 성공 손실·미평가·전체 작업량을 함께 비교한다.
4. 새 후보가 없거나 저장 근거상 지지 가능 입력 상한이 5개 이하면 전체 모델·3D 재평가로 진행하지 않는다. 알려진 실패의 다음 순위 원료를 연속 시도하지 않고 근거 보강 또는 별도 자산 확장 항목으로 넘긴다. 고정 자산 P1의 미완료 상태는 그대로 보고한다.

**한 입력 생성 대조의 비용·해석:** 관련 단위 검사 19개와 독립 검토 후 한 번 실행했으며 종료 코드 0, 실행 전후 바인딩 일치를 확인했다. 비교 문맥 4개·원료 평가 64회에서 추가 표현 지문 56회, 부위 매칭 47회, 자격 확인용 역할 매칭 128회, 구조 작업 21,084단위를 사용했다. 전체 검색 지문은 49,379회, 카탈로그 행 방문은 262,144회, 정확 경로 감사는 8회다. 원료 교체 2건·유지 2건·기존 선택으로 복귀 13건을 모두 보존했다. 새 경로의 원 입력 Tanimoto는 0.3529–0.38로 기준 0.35를 통과했지만, 높은 구조 유사도나 활성 보존을 의미하지 않는다. 이 생성 대조의 모델·3D 호출은 0회였고 생성 시간 60.538초는 카탈로그 적재를 제외한 단일 관측이다.

**별도 전방 대조의 결과:** 3경로 모두 모델 실행 전 엄격 경로 감사(`product_limit=64`)를 통과했다. 고정한 순서에서 모델 요청 4회, 재사용 2회, 입력 208토큰·출력 560토큰으로 총 6단계를 평가했다. 지지된 두 경로는 첫 단계 2순위·두 번째 단계 1순위에서 정확히 일치했다. 일부 다른 예측 구조는 무효였지만, 기존 규약은 완결된 유효 예측 중 정확 일치가 하나 이상 있는지를 판정하므로 규약 변경은 없었다. 세 번째 경로의 첫 단계는 유효한 상위 3개 모두 불일치했으며, 두 번째 단계가 일치해도 전체 경로 지지로 세지 않았다. 단위 검사 3개·독립 사전/결과 검토, 종료 코드 0과 실행 전후 바인딩 일치를 확인했다. 반응 조건 추가·새 원료 검색·3D는 수행하지 않았다. 이 진단을 P1 전체 성적이나 최종 적격 후보 수로 승격하지 않는다.

**동일 원료 목록 재사용 — 구현·v22 전체 대조 완료:** 기본 비활성 `route_first.share_identical_catalog_pools`는 완전히 계산된 특성 구간·유효 반응 역할이 같은 목록의 정렬 결과만 공유한다. 원 입력별 지문·anchor·역할·입체 판정과 후보 행 방문은 각각 수행하며, 불완전한 metadata·일부 목록·시간 만료는 공유 근거로 삼지 않는다. 관련 테스트 101개와 독립 검토 후 [고정 12입력 v22 대조](../benchmarks/results/synthesis-route-development-20261023/route-first-v2-pre-evidence-v22.json)를 한 번 실행했다. **기존 59생성물·66정확 경로, 최초 3개 순서, 과거 qualified 3경로와 N–H 지지 경로를 모두 보존했지만 추가·손실은 0개다.** 공유 대상 115건에서 버킷 정렬 비용 95,290단위를 회피했고, 추가 탐색을 포함한 실제 총 정렬은 61,250회·행 방문은 8,778회 감소했다. 반면 검색 지문은 3,390회, 조합·생성물 인스턴스는 각각 14건 증가했다. 별도 진단 지문은 701→703회다. 생성 시간 합계 553.621→558.862초는 단일 관측으로 속도 효과를 주장하지 않는다. 같은 후보 집합이므로 조건부 상한 5/12개와 실제 주 지표 4/12개를 유지하고 모델·3D를 반복하지 않는다. 이 옵션은 기본 비활성으로 보존하며 P1 성능 개선으로 채택하지 않는다.

최근 [반응 부위 대조](../benchmarks/results/synthesis-route-development-20261023/endpoint-locus-r2-control-v1.json)는 두 개발 입력의 지지 13기록을 배제하지 않고 목표 불일치 2기록을 구분했지만, 다른 불일치 1기록은 구분하지 못했다. [현재 pool의 고정 원료 선택](../benchmarks/results/synthesis-route-development-20261023/current-pool-source-feasibility-v1.json) 후 [동일 상대와의 생성 대조](../benchmarks/results/synthesis-route-development-20261023/current-pool-same-partner-control-v1.json)에서 새 생성물은 Tanimoto **0.349057 < 0.35**, 극성 보존 상한 **0.70 < 0.75**로 탈락했다. 이 선택 변형은 종료했다.

**donor 진단·기록 복구 완료:** [고정 관측 기록](../benchmarks/results/synthesis-route-development-20261023/donor-feature-diagnostic-v1.json)에서 고정 대안 원료는 donor 0개, guide는 2개였다. 그러나 지지 단계 기록 2건도 원료 2개·guide 3개로 줄어 일반적인 donor 보존 필수 조건에 반례가 있었다. 더 좁은 반응 부위 조건과의 결합은 검증되지 않았다. 구조 34개의 특징 관측과 부위 매칭 44회를 수행한 뒤 마지막 해시 기록의 변수명 충돌로 원래 실행은 종료 코드 1이 됐다. 별도 JSON 전용 복구가 종료 코드 0으로 완료됐고 저장 관측의 완전성과 복구 전후 바인딩을 확인했다. 원래 실행의 종료 시점 검증 누락은 그대로 남긴다. 화학 계산·모델·3D 재실행, 새 원료 검색·생성, P1 지표 변경은 없었다.

| 다음에 확보할 근거 | 허용되는 후속 조치 |
|---|---|
| 고정 예산에서 적합 원료/경로가 실제 선택·연결 결함으로 누락됨을 재현 | 특정 원료 ID를 주입하지 않는 일반 수정과 양성/음성 회귀 검사. 기존 성공 손실을 포함한 전체 공급 대조. |
| 재생되지만 전방 모델이 다른 부위·다중 치환을 예측 | 정확한 반응 관찰/조건 대응과 경쟁 부위 근거 조사. 현재 모델 불일치는 유지하며 근거 없는 조건을 입력해 일치를 찾지 않는다. |
| 기존 규칙·원료로 필요한 역할/입체 문맥을 다룰 근거가 부족 | 출처·선택성·원자 대응을 갖춘 **별도 자산 확장 실험**. 기존 자산과 확장 자산의 성과를 분리하고 새 기준선을 고정한다. 이것을 고정 자산 P1 달성으로 세지 않는다. |
| 관측이 불완전하거나 상한에 도달 | 미확인 범위와 확보된 양성 근거를 기록한다. 원료 전체 부재·합성 불가능으로 일반화하지 않는다. |

현재 `building_block_top_k=2`는 **반응 전에 선택하는 원료 수**다. 더 많은 원료로 생성물을 만든 뒤 2개를 남기는 방법은 상한 변경이므로 같은 P1 비교로 넣지 않는다. v21의 모든 대기 생성물은 순위·입장 검사를 받았으며 단순 입장 순서 변경으로 미생성 경로를 복구할 근거도 없다. 고정된 실패 원료의 다음 순위, ester 변형, 임계값·가중치 변경을 연속 시도하지 않는다.

## 검증·반영 기준

- **P1 고정 조건:** 동일 catalog/rules, 최대 2단계, 원료 top-2와 기존 탐색·모델·3D 상한. 원 입력 Morgan bit Tanimoto 0.35, 극성 보존 0.75, 형태 0.70, 약리 특징 0.50 및 기존 물성·입체·scaffold 관문을 유지한다. 정확한 설정·자산·작업량은 [고정 비교 기록](../benchmarks/results/synthesis-route-development-20261023/actual-comparison-v2-freeze.json)과 각 버전 기록으로 추적한다.
- **채택 주 지표:** 정확한 변경 scaffold 생성물의 전체 경로 감사와 모든 단계의 전방 지지를 갖춘 입력 최소 6/12개. 최종 qualified, 입력/생성물 쌍, 경로 수, 기존 성공 손실, 예산 미평가·오류와 전체 비용은 별도 보고한다. 임계값을 보고 사후에 주 지표를 교체하지 않는다.
- **실행 관리:** 가설/선택 순서/소스/자료/상한을 실행 전에 고정한다. 변경된 후보가 없으면 전체 모델·3D를 반복하지 않는다. 실패·중단 실행과 비용을 보존하며, 완료한 화학 계산을 기록 오류 때문에 반복하지 않는다.
- **일반화 검증:** 현재 12입력은 반복 사용한 개발 패널이다. 별도 scaffold·입체 복잡도·전하·고리 유형 패널을 결과 확인 전에 고정하고, 표적/구조 중복과 모델 학습 중복의 확인 가능 범위를 기록한다. 같은 예산의 기준선·구성요소 제거 대조와 입력별 성공/실패·비용을 보고한다.
- **반영 전 검사:** 기본/OFF 동일성, 정확 생성물·입체, 예산·캐시·출처·보고 회귀를 확인한다. 구현 커밋 `9989230`의 [검증 기록](../benchmarks/results/synthesis-route-development-20261023/marked-policy-port-validation-v1.json)은 집중 검사 109개, 전체 저장소 **3,686통과·76건너뜀·19하위 검사 통과·실패 0개**, Ruff·컴파일·독립 검토 통과다. 건너뛴 선택 의존성/별도 환경 검사는 완료로 세지 않는다. 원료 선택의 성능 채택과 모델·3D 전체 비교는 별도이며 아직 완료하지 않았다.

현재 단계에서 “합성 가능한 scaffold를 보장한다”고 말할 수는 없다. 제안 경로의 어떤 단계가 재생·계산 지지·문헌 근거·실험 확인을 갖췄는지 명확히 제시하고, 그 근거가 있는 후보와 입력 범위를 늘리는 것이 이번 개선의 완료 방향이다.
