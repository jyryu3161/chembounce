# 합성 경로 우선 개발 계획 (2026-10-24)

목표는 **입력의 필요한 구조·입체·약리 특징을 보존하면서 scaffold가 달라지고, 구체 원료부터 정확한 최종 생성물까지 검토 가능한 합성 경로를 가진 후보**를 제안하는 것이다. 계산 방법론 논문을 우선하며 합성·활성 실험 협업은 미정이다. 계산 경로 검증, 실제 합성 성공, 활성 보존을 각각 구분한다.

**P1은 미완료다.** 최근 전체 모델·3D 비교에서 모든 단계가 계산적으로 지지된 입력은 **4/12개**, 기준선은 **5/12개**, 채택 기준은 **최소 6/12개**다. 실험 코드는 `feat/route-first-generation`에 유지한다. 현재 기본 추천 프로필은 `qualified-selective-engineering-v7`이며 실험 선택 옵션은 기본 비활성이다. P1 채택 전에는 해당 기능을 `develop`에 병합하지 않는다.

현재 계획은 이 문서가 기준이다. 과거의 상세 실험·수정·비채택 판단은 [개발 이력](SYNTHESIS_ROUTE_HISTORY.md)에 원문과 해시를 보존했다.

## 실행 순서와 완료 기준

P1의 성능 목표를 유지하면서, **단계별 검토 기능과 합성 근거 보강을 함께 진행한다.** 경로 수·깊이를 늘리는 일보다 실패한 단계와 근거 누락을 확인하는 일이 먼저다.

| 순서 | 작업·코드 접점 | 구체 산출물·완료 조건 |
|---|---|---|
| 1. 현재 진단 종료 — 완료 | [donor 관측·복구 기록](../benchmarks/results/synthesis-route-development-20261023/donor-feature-diagnostic-v1.json)을 보존했다. | 13개 지지 단계 기록·19개 원료/guide 비교·고정 원료 5개·기존 생성물 3개를 확인했다. 지지 기록 2건의 반례로 일반적인 donor 수 보존 필수 조건을 기각했다. 원래 실행 오류와 종료 시점 검증 누락을 보존하며 다음 순위 원료 검색으로 이어가지 않는다. |
| 2. 경로 검토 화면 | `report.py`의 저장 자료 조립·단계 표시를 확장한다. | 추천 0개여도 **평가 후 미선택 경로 최대 16개**를 저장 순서로 표시하고 전체/표시/생략 수를 제공한다. 정확한 중간체, 기대/예측 생성물, 실패 단계, 조건 누락, 원료 출처를 추적한다. 아래 표시 규약과 음성 fixture를 통과해야 완료다. |
| 3. 조건·선택성 근거 | `evidence.py`, `reaction_records.py`, `catalog.py`, `report.py`의 필드를 연결한다. | 단계별 반응물·생성물 대응과 함께 시약·촉매·용매·온도·시간·당량·보호기·출처를 연결한다. 정확 반응 관찰과 유사 반응 참고, 카탈로그 등재와 현재 재고를 구분한다. 데이터/규칙 확장은 새 버전으로 고정하고 양성·음성 대응 검사를 갖춘다. |
| 4. P1의 다음 경로 생성 수정 | `route_first.py`의 확인된 손실 지점만 수정한다. | 기존 top-2 원료 선택·beam·예산에서 새로운 정확 경로를 공급할 구체 근거가 먼저 필요하다. 실패한 가중치/원료 변형을 반복하지 않는다. 한정 대조에서 기존 관문을 통과한 경우에만 일반 구현·고정 12입력 공급 대조로 진행한다. 현재 확정된 새 선택 정책은 없다. |
| 5. 전체 경로 대조·채택 | 동일 자산·예산에서 실제 전방 모델과 3D/qualification을 평가한다. | 새 후보 집합에 전체 지지 입력이 5개를 넘을 근거가 있고 관련 테스트·독립 검토·전체 저장소 검증을 통과했을 때 실행한다. 실제 전체 경로 지지 **최소 6/12개**가 P1 기준이며 qualified·손실·미평가·비용도 보고한다. |
| 6. 대체 경로·독립 검증 | P1 이후 `routes.py`, `workflow.py`에서 대체 연결 순서와 공유 중간체를 다룬다. | 동일 생성물의 대체 경로를 각각 감사하고 정확히 같은 예측 요청만 캐시로 공유한다. 별도 고정 입력 패널에서 기준선과 비교한다. 3단계 이상·새 자산·새 예산은 별도 실험으로 관리한다. |

2–3번은 P1 성공률을 올렸다고 주장하지 않는 독립 작업이다. 구현은 **GPT-6-Sol medium**, 독립 검토는 **Astra**로 진행한다. 불확실한 실험 결과를 날짜로 약속하는 대신 위 산출물 단위로 완료 여부를 보고한다.

## 경로 검토 화면의 최소 규약

각 경로에서 **입력 → 최종 구조 → 원료 → 정확한 중간체 → 단계별 생성물**을 추적한다. 다음 상태를 한 점수로 합치지 않는다.

| 표시 항목 | 판정 규약 |
|---|---|
| 입력과의 관계 | 원 입력 기준 2D 유사도, 3D 형태·약리 특징, 지정 입체 보존, 실제 scaffold 변경 범위를 별도로 표시한다. |
| 경로 결합 | 그래프 node ID, 순서 있는 반응물, 정확한 생성물·규칙 ID·경로 바인딩으로 재생/감사/전방 기록을 연결한다. 다른 위치·입체이성질체의 근거를 옮기지 않는다. |
| 단계별 계산 근거 | 규칙 재생, 원자/입체 감사, 전방 예측의 완료·유효·일치 상태를 나누고 기대/예측 구조를 보여준다. 한 단계라도 미평가이면 전체 지지로 표시하지 않는다. |
| 반응 맥락 | 조건 제공 여부와 모델 사용 여부를 구분한다. 현재 ReactionT5 어댑터는 반응물·시약을 사용하며 온도·시간은 사용하지 않는다. ORD 연결은 보고용이며 자동 승인 근거가 아니다. |
| 원료·문헌 근거 | ID/구조/출처, SKU·조회일·재고 확인 여부, 정확 반응/유사 반응 여부를 표시한다. 출처가 없거나 대응이 모호한 조건·수율은 미확인이다. |
| 실패·누락 | 불일치, 예산 미평가, 자료 누락/손상, 실행 오류를 구별한다. 계산 불일치를 실험 합성 실패로 표시하지 않는다. `qualified`는 현재 계산 관문 통과 상태다. |

`_route_steps`는 선택된 적격 경로를 전제로 하므로 거절 경로에 그대로 적용하지 않는다. 그래프/근거 결합 검증과 적격성 판정을 분리해, 거절 근거도 표시하되 누락·모순을 확인된 경로로 승격하지 않는다. 선택 주 경로와 중복 표시하지 않고 추천 목록·최종 판정은 유지한다.

**완료 검증:** 추천 0개/거절 2단계, 부분·누락·손상된 예측, 잘못된 node/반응물/생성물 결합, 선택 경로 중복, HTML escaping, 표시 상한/생략 수, 기존 선택 후보 보고 회귀를 확인한다. 이 기능의 실행은 저장 자료만 사용하며 반응 생성·모델·3D를 호출하지 않아야 한다.

## P1의 다음 변경을 결정하는 기준

최근 [반응 부위 대조](../benchmarks/results/synthesis-route-development-20261023/endpoint-locus-r2-control-v1.json)는 두 개발 입력의 지지 13기록을 배제하지 않고 목표 불일치 2기록을 구분했지만, 다른 불일치 1기록은 구분하지 못했다. [현재 pool의 고정 원료 선택](../benchmarks/results/synthesis-route-development-20261023/current-pool-source-feasibility-v1.json) 후 [동일 상대와의 생성 대조](../benchmarks/results/synthesis-route-development-20261023/current-pool-same-partner-control-v1.json)에서 새 생성물은 Tanimoto **0.349057 < 0.35**, 극성 보존 상한 **0.70 < 0.75**로 탈락했다. 이 선택 변형은 종료했다.

**donor 진단·기록 복구 완료:** [고정 관측 기록](../benchmarks/results/synthesis-route-development-20261023/donor-feature-diagnostic-v1.json)에서 고정 대안 원료는 donor 0개, guide는 2개였다. 그러나 지지 단계 기록 2건도 원료 2개·guide 3개로 줄어 일반적인 donor 보존 필수 조건에 반례가 있었다. 더 좁은 반응 부위 조건과의 결합은 검증되지 않았다. 구조 34개의 특징 관측과 부위 매칭 44회를 수행한 뒤 마지막 해시 기록의 변수명 충돌로 원래 실행은 종료 코드 1이 됐다. 별도 JSON 전용 복구가 종료 코드 0으로 완료됐고 저장 관측의 완전성과 복구 전후 바인딩을 확인했다. 원래 실행의 종료 시점 검증 누락은 그대로 남긴다. 화학 계산·모델·3D 재실행, 새 원료 검색·생성, P1 지표 변경은 없었다.

| 다음에 확보할 근거 | 허용되는 후속 조치 |
|---|---|
| 고정 예산에서 적합 원료/경로가 실제 선택·연결 결함으로 누락됨을 재현 | 특정 원료 ID를 주입하지 않는 일반 수정과 양성/음성 회귀 검사. 기존 성공 손실을 포함한 전체 공급 대조. |
| 재생되지만 전방 모델이 다른 부위·다중 치환을 예측 | 정확한 반응 관찰/조건 대응과 경쟁 부위 근거 조사. 현재 모델 불일치는 유지하며 근거 없는 조건을 입력해 일치를 찾지 않는다. |
| 기존 규칙·원료로 필요한 역할/입체 문맥을 다룰 근거가 부족 | 출처·선택성·원자 대응을 갖춘 **별도 자산 확장 실험**. 기존 자산과 확장 자산의 성과를 분리하고 새 기준선을 고정한다. 이것을 고정 자산 P1 달성으로 세지 않는다. |
| 관측이 불완전하거나 상한에 도달 | 미확인 범위와 확보된 양성 근거를 기록한다. 원료 전체 부재·합성 불가능으로 일반화하지 않는다. |

현재 `building_block_top_k=2`는 **반응 전에 선택하는 원료 수**다. 더 많은 원료로 생성물을 만든 뒤 2개를 남기는 방법은 상한 변경이므로 같은 P1 비교로 넣지 않는다. v21의 모든 대기 생성물은 순위·입장 검사를 받았으며 단순 입장 순서 변경으로 미생성 경로를 복구할 근거도 없다. 고정된 실패 원료의 다음 순위, ester 변형, 임계값·가중치 변경을 연속 시도하지 않는다.

## 검증·반영 기준

- **P1 고정 조건:** 동일 catalog/rules, 최대 2단계, 원료 top-2와 기존 탐색·모델·3D 상한. 원 입력 Morgan bit Tanimoto 0.35, 극성 보존 0.75, 형태 0.70, 약리 특징 0.50 및 기존 물성·입체·scaffold 관문을 유지한다. 정확한 설정·자산·작업량은 [고정 비교 기록](../benchmarks/results/synthesis-route-development-20261023/actual-comparison-v2-freeze.json)과 각 버전 기록으로 추적한다.
- **채택 주 지표:** 정확한 변경 scaffold 생성물의 전체 경로 감사와 모든 단계의 전방 지지를 갖춘 입력 최소 6/12개. 최종 qualified, 입력/생성물 쌍, 경로 수, 기존 성공 손실, 예산 미평가·오류와 전체 비용은 별도 보고한다. 임계값을 보고 사후에 주 지표를 교체하지 않는다.
- **실행 관리:** 가설/선택 순서/소스/자료/상한을 실행 전에 고정한다. 변경된 후보가 없으면 전체 모델·3D를 반복하지 않는다. 실패·중단 실행과 비용을 보존하며, 완료한 화학 계산을 기록 오류 때문에 반복하지 않는다.
- **일반화 검증:** 현재 12입력은 반복 사용한 개발 패널이다. 별도 scaffold·입체 복잡도·전하·고리 유형 패널을 결과 확인 전에 고정하고, 표적/구조 중복과 모델 학습 중복의 확인 가능 범위를 기록한다. 같은 예산의 기준선·구성요소 제거 대조와 입력별 성공/실패·비용을 보고한다.
- **반영 전 검사:** 현재 소스의 관련 테스트와 전체 저장소 검증을 완료하고 기본/OFF 동일성, 정확 생성물·입체, 예산·캐시·출처·보고 회귀를 확인한다. 최근 전체 실행은 3,626통과·76건너뜀·소스 해시 fixture 1실패였고, fixture 수정 후 집중 검사는 통과했다. 이후 전체 스위트가 모두 통과했다고 표현하지 않는다.

현재 단계에서 “합성 가능한 scaffold를 보장한다”고 말할 수는 없다. 제안 경로의 어떤 단계가 재생·계산 지지·문헌 근거·실험 확인을 갖췄는지 명확히 제시하고, 그 근거가 있는 후보와 입력 범위를 늘리는 것이 이번 개선의 완료 방향이다.
