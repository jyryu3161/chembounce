# Validation record and publication scope

This file distinguishes verified software behavior from scientific conclusions.
A software repair and a faster similarity kernel do not, on their own, establish
superior scaffold-hopping chemistry or suitability for a particular journal.

The [completed original frozen generation study](RESEARCH_VALIDATION.md#completed-original-frozen-generation-study)
records all 630 planned attempts under the original 39-file source inventory,
including timeouts and an infrastructure-missing outcome. Its all-method tables,
separate uncertainty/bounds and portable statistical replay are distinct from
current-pipeline validation and the supplementary comparator study. Route replay
and common 3D coverage do not establish activity or experimental synthesis success.
The separate [completed common-forward audit](RESEARCH_VALIDATION.md#completed-original-common-forward-audit)
adds exact query/seed paired statistics with explicit route and conditional
eligibility. Its predictor is also the selection gate, so agreement is not
independent experimental synthesis validation.

## Legacy ADP defect

`benchmarks/legacy_adp.json` was generated by executing the original 1.0 source
(`5780007`, now preserved as `v1.0.0`) in a
temporary directory, with only `RDBASE` supplied to let pip-installed RDKit import.
The exact reported ADP produces three automatic scaffolds: both purine-containing
scaffolds fail with `AtomKekulizeException`, and the ribose scaffold fails with an
`EditableMol.ReplaceAtom(None, ...)` argument error. The 1.0 screening loop catches
these exceptions and continues, explaining a header-only final table regardless
of available replacement candidates. ADP also violates donor/acceptor filters;
that is a separate issue, not the cause of the attachment exceptions.

Reproduction (uses `v1.0.0`, requires MolVS and PubChemPy):

```bash
python benchmarks/reproduce_legacy_adp.py
```

The 2.0 regression suite uses the exact supplied SMILES and asserts valid connected
products for all three scaffold families. It tests that retained ribose stereo and
phosphates survive purine replacement, and that same-scaffold reconstruction can
recover inputs with stereocenters, isotopes, double bonds and bridged remnants.

## Search-kernel benchmark

```bash
python benchmarks/benchmark_search.py --rows 100000 --repeats 5
```

`benchmarks/search_100k.json` stores all repetitions, platform and dependency
versions. Two separate workers search the same seeded synthetic sparse bits.
Input construction and loading are excluded from elapsed search times. The legacy
worker uses full AND/OR matrices and a global sort; the packed worker uses chunks
and bounded top-k selection. Equal-score ordering is normalized to row index to
compare outputs. All top-100 indices and scores must match exactly.

The recorded run obtained 0.3764 s versus 0.1677 s median (2.24×), fingerprint arrays
of 204.8 MB versus 25.6 MB, and sampled worker RSS of 527.9 versus 161.9 MiB. RSS is
sampled every 2 ms and includes worker imports/input arrays. Earlier-process high
watermarks are deliberately not used. These figures do not establish full-workflow
speedup, scaling across hardware, or molecular-quality improvement.

## Whole-workflow evaluation

`benchmarks/molecules.json` is a small hand-selected engineering stress panel:
ADP, the original README example, an aromatic ether, a chiral sidechain, fused rings,
a macrocycle and an acyclic control. It is not a statistically representative
chemical benchmark. To evaluate on the published library:

```bash
python benchmarks/benchmark_workflow.py \
  --fingerprint-db data/fingerprints_mw250_v2 \
  --output benchmark-results/published-mw250
```

Use the full database as a separate experimental condition. Keep all individual
manifests, summaries, generated candidates and resource reports. The script checks
sanitization/connectivity, uniqueness, caps and similarity thresholds and records
zero-result inputs rather than dropping them from the denominator.

The ambiguous tirzepatide name lookup was resolved to the explicitly identified

The isolated attachment comparison bypasses library search and property/3D filters.
Both versions receive the same canonical input, stereo-free full Murcko fragment,
and four replacements: that same fragment as an identity control, pyridine,
piperidine and morpholine. There are 64 calls per condition, each capped at ten
returned structures. Original 1.0 source runs unchanged with only the documented
`RDBASE` import shim. It receives the legacy beam argument of 50, but its internal
search does not honor the same pruning bound. A worker wall limit of ten seconds
after imports provides the common external budget; timed-out workers are terminated.

Table values count calls, not molecules. Legacy errors comprised 52 aromatic
kekulization errors, eight attachment argument errors and four index errors. This

published run or measure superiority over other scaffold-hopping methods.

After capacity pruning, a [repeat at beam 50](../benchmarks/results/attachment-final.json)
on clean commit `d7d4d61` returned exactly the same ordered candidate lists for all
mutually completed calls. It again had 56 successful calls, six empty and two
timeouts. All 560 returned entries passed sanitization, connectivity, heavy-atom /
isotope accounting, uniqueness, caps, score agreement and retained-fragment stereo
checks. The retention queries constrain atom degrees and have negative controls
for inverted stereo and lost isotopes. They are necessary substructure checks,
not a unique atom-mapping proof for repeated identical substituents.

Of these entries, 140 came from identity controls and 420 from the three alternative
replacements. All 420 latter entries changed the stereo-free Murcko scaffold, but
only 20 met a final count-Tanimoto threshold of 0.5 (median 0.151). Thus structural
validity in this assembly experiment is not equivalent to useful workflow output.
Larger beams also increased timeouts; no monotonic quality or speed claim follows.

The [whole-workflow record](../benchmarks/results/publication-workflow/summary.tsv)

## Evidence still required for a journal manuscript

The repository now supports reproducible software experiments. A claim of novel or
superior chemistry additionally needs a defined scientific question and empirical
evidence. Before manuscript submission:

1. Establish a licensed, versioned multi-class evaluation set and preregistered
   inclusion criteria; control overlap with the scaffold library and known actives.
2. Add independent scaffold-hopping baselines beyond the legacy assembly comparison, under matched libraries,
   compute budgets and output counts. Include per-input failures and confidence
   intervals, not only aggregate successful cases.
3. Measure diversity, scaffold novelty, preserved pharmacophores and chemical
   plausibility. Include controlled beam-width, similarity, library-size, filter,
   stereochemistry and conformer-seed ablations.
4. Obtain chemistry review and task-appropriate activity/synthesis evidence for
   selected candidates. Similarity, QED and SA are not substitutes for those data.
5. Resolve project and third-party licensing, freeze a release and data artifacts,
   archive an executable environment and deposit the exact experiment outputs.

These are manuscript-level requirements, not claims that this patch has already
completed comparative or experimental validation. Version 2.0 on `develop` remains a
publicly identifiable development version until release criteria are satisfied.

## Develop review, 2026-10-15

Reviewed the working tree based on `9dab6cb`, including the integrated hopping CLI,
catalog/reaction verification, conformer scoring, refinement and continuation.
The [machine-readable audit](../benchmarks/results/develop-review-20261015.json)
records runtime source hashes, package versions and measured results.

The original 159 tests passed, but targeted negative controls exposed defects
outside their coverage. The review fixes:

- Reaction execution accepted a nonmatching stereocenter when a different site
  on the same substrate matched the rule. Chirality is now enforced through
  RDKit's [reaction matching parameters](https://www.rdkit.org/docs/source/rdkit.Chem.rdChemReactions.html#rdkit.Chem.rdChemReactions.ChemicalReaction.GetSubstructParams)
  during execution, in addition to the existing reactant-role check.
- Isotope-only and retained ring-stereochemistry changes could count as a new
  Murcko scaffold. Hopping now compares scaffold connectivity and atom/bond types
  without isotope/stereo labels; exact replay and preservation checks remain.
- New candidates for an early design could consume the global scoring budget
  before a later design's carried candidates. All carried designs are now
  processed before fresh proposals.
- The integrated `--overwrite` path could replace hopping files before rejecting
  an existing synthesis directory. It now rejects that destination beforehand.
- Invalid search/conformer settings are rejected before hopping, and both CLIs
  report model runtime errors with exit code 2 while retaining workflow diagnostics.

The updated suite passed **177 tests** on RDKit 2025.09.6. Minimum dependencies
(RDKit 2023.09.6, NumPy 1.24.4, pandas 2.0.3, SciPy 1.10.1) passed **138 tests**, with
four skips for unavailable optional modules. Lint, formatting and whitespace
checks passed. The retained ring-stereo negative control was additionally rerun
using two fused-ring stereoisomers; both scaffold-change negative controls passed.

Live SynLlama-1B-2M-91rxns inference on an NVIDIA L40 used the full 238,542-entry
catalog, four samples, six screening conformers, and refinement of the top three
products with eight conformers at seeds 42/43/44. It screened six unique products
and returned three refined products. All three changed the original scaffold;
their selected routes replayed exactly using IDs looked up in the original
catalog. Both Tanimotos matched independent recomputation. Exported SDF coordinates
reproduced pharmacophore scores within `1.08e-5`; the two orientations of each
candidate preserved pair distances within `0.000191` angstrom.

Continuation used those saved model responses, six alternative blocks per leaf,
two expansion rounds, 32 routes per starting route and a 64-pair scoring budget.
The screening pool grew from **6 to 27** with **zero prior products lost**, and
three products passed refinement. One additional unique product failed 3D scoring;
failures remain in route evidence. Selected routes, both Tanimotos and exported
coordinates were rechecked. A separate integrated CLI run generated the thiazole
design by replacing the oxazole ring and passed it to synthesis verification,
using these actual saved proposals and a small catalog subset. Its required core
was retained, and one verified result was returned.

Pareto ranking now computes pairwise dominance once, reducing worst-case work
from cubic to quadratic, with quadratic Boolean storage. A three-repeat median
microbenchmark on 256 candidates preserved every front:

| Pool | Before | After | Speedup |
| --- | ---: | ---: | ---: |
| Random eight-metric values | 33.10 ms | 6.82 ms | 4.85x |
| Fully ordered dominance chain | 1510.92 ms | 9.02 ms | 167.45x |

These are isolated ranking timings on a shared host, not whole-workflow speedups.
This is a single integration example without independent held-out generalization
evidence; the pretrained chemical inventory is unknown. The pinned upstream
prompt contains no molecule-specific examples, so no prompt overlap is claimed. Catalog membership and reaction replay do not
establish yield, selectivity, reagent/condition completeness, current stock or
biological activity. Refinement scores remain sampling-sensitive heuristics.
